SECTION A — INHERITANCE

1. Basics of Inheritance

⚡ Quick Exam Answer (2–5 Marks)

Definition: Inheritance is a fundamental concept of Object-Oriented Programming (OOP) that allows a new class (Derived Class) to acquire the properties, behaviors, and data members of an existing class (Base Class).

Key Points:

  • Promotes code reusability and reduces software development time.
  • Establishes an IS-A relationship between classes (e.g., a Dog IS-A Animal).
  • Existing class is called the Base Class (or Parent Class); the new class is called the Derived Class (or Child Class).

Detailed 10-Mark Explanation

Inheritance is one of the four foundational pillars of Object-Oriented Programming, alongside Encapsulation, Abstraction, and Polymorphism. In software development, writing code from scratch for every single component is highly inefficient. Real-world objects often share common attributes and behaviors. For instance, both a Car and a Truck share common attributes such as speed, fuel capacity, and engine state, alongside common actions like accelerate and brake. Inheritance allows programmers to define these common features in a generalized class and then extend that class to create more specific classes without redefining the existing logic.

The class whose properties are inherited is termed the Base Class (or Parent / Super Class). The class that inherits these properties is known as the Derived Class (or Child / Sub Class). The derived class inherits all non-private members of the base class and can also add its own unique variables and functions, or overwrite existing behaviors.

Why Inheritance is Required:

  • Code Reusability: Once a base class is written, tested, and debugged, its code can be reused freely in child classes. This eliminates redundancy and lowers overall software maintenance costs.
  • Transitive Nature: If Class C inherits from Class B, and Class B inherits from Class A, then Class C automatically inherits features of Class A as well.
  • Extensibility: Existing classes can be adapted to meet new application demands without modifying the original code, preserving backward compatibility.
  • Polymorphic Architecture: Inheritance forms the structural groundwork required for runtime polymorphism using virtual functions.

Syntax of Inheritance in C++:

C++ Syntax
class DerivedClass : access_specifier BaseClass {
    // Body of the derived class
};

Access Specifiers in Inheritance: The access specifier determines how base class members are made available inside the derived class:

  • Public Inheritance (public): Public members of the base class become public members of the derived class. Protected members of the base class become protected members of the derived class. Private members remain private to the base class and cannot be accessed directly.
  • Protected Inheritance (protected): Public and protected members of the base class both become protected members of the derived class.
  • Private Inheritance (private): Public and protected members of the base class both become private members of the derived class.

Visual Diagram: Basic Inheritance

Base Class (Parent)
↓
Derived Class (Child)

C++ Example Program

Simple_Inheritance.cpp
#include <iostream>
using namespace std;

// Base Class
class Animal {
public:
    void eat() {
        cout << "This animal eats food." << endl;
    }
};

// Derived Class inheriting publicly from Animal
class Dog : public Animal {
public:
    void bark() {
        cout << "The dog barks: Woof! Woof!" << endl;
    }
};

int main() {
    Dog myDog;
    // Calling inherited member function
    myDog.eat();
    // Calling derived class's own member function
    myDog.bark();
    return 0;
}

Code Explanation

In this program, Animal is created as a Base Class with a single public function eat(). The Dog class is declared as a Derived Class using public inheritance (class Dog : public Animal). Because of public inheritance, the Dog class acquires public access to eat(). Inside the main() function, an object myDog of type Dog is instantiated. myDog can invoke both its inherited method eat() and its own unique method bark() seamlessly.

📌 Important Exam Points to Remember
  • Private members of a base class are NEVER directly accessible in a derived class; they are inherited but hidden.
  • Protected access specifier acts like private to outer code, but allows child classes to access the members directly.
  • Default access mode in inheritance is private if not specified (e.g., class Derived : Base is private by default).

2. Types of Inheritance

⚡ Quick Exam Answer (2–5 Marks)

C++ supports 5 forms of inheritance based on how base classes and derived classes are structured:

  1. Single Inheritance: One base class, one derived class.
  2. Multilevel Inheritance: A class derived from another derived class (chain).
  3. Multiple Inheritance: One derived class inheriting from two or more base classes.
  4. Hierarchical Inheritance: Multiple derived classes inheriting from a single base class.
  5. Hybrid Inheritance: Combination of two or more types of inheritance.

Detailed 10-Mark Explanation of Each Type

1. Single Inheritance

Single inheritance is the simplest form of inheritance where one child class derives directly from a single parent class. It establishes a direct 1-to-1 hierarchy. It is typically used when a specialized entity needs to add extra attributes to a general concept.

Class A (Base)
↓
Class B (Derived)
2. Multilevel Inheritance

In multilevel inheritance, a class is derived from another derived class, forming a chain of inheritance. The intermediate derived class acts as both a child class to its parent and a parent class to its descendant. For example: Person -> Employee -> Manager. The bottom-most class inherits attributes from every level above it.

Class A (Grandparent)
↓
Class B (Parent)
↓
Class C (Child)
3. Multiple Inheritance

Multiple inheritance occurs when a single derived class simultaneously inherits properties from two or more separate base classes. Syntax requires separating base classes with commas: class Derived : public Base1, public Base2. While powerful for combining features (e.g., a SmartPhone inheriting from Camera and Phone), it can introduce severe ambiguity problems if both base classes contain members with identical names.

Class A
Class B
↘ ↙
Class C (Derived)
4. Hierarchical Inheritance

In hierarchical inheritance, a single base class serves as the parent for multiple derived classes. It creates a tree-like hierarchy structure. For example, a base class Shape can be inherited by Circle, Rectangle, and Triangle. Every derived class shares base features but provides its own specialized functionality.

Class A (Base)
↙ ↘
Class B
Class C
5. Hybrid Inheritance

Hybrid inheritance is created by combining two or more distinct types of inheritance within a single program. A common configuration is combining Multiple and Hierarchical inheritance (forming the classic diamond arrangement). Because hybrid structures are complex, they frequently cause member duplication and ambiguity issues, requiring C++ features like Virtual Base Classes to resolve them properly.

C++ Example: Multiple Inheritance

Multiple_Inheritance.cpp
#include <iostream>
using namespace std;

class Printer {
public:
    void printDoc() {
        cout << "Printing document..." << endl;
    }
};

class Scanner {
public:
    void scanDoc() {
        cout << "Scanning document..." << endl;
    }
};

// Derived from both Printer and Scanner
class AllInOnePrinter : public Printer, public Scanner {
public:
    void faxDoc() {
        cout << "Sending fax..." << endl;
    }
};

int main() {
    AllInOnePrinter device;
    device.printDoc(); // inherited from Printer
    device.scanDoc();  // inherited from Scanner
    device.faxDoc();   // native to AllInOnePrinter
    return 0;
}

3. Virtual Base Classes

⚡ Quick Exam Answer (2–5 Marks)

Definition: A Virtual Base Class is used in C++ to prevent duplicate copies of a base class from being inherited into a child class when using hybrid or multipath inheritance (The Diamond Problem).

Syntax: class B : virtual public A { ... };

Detailed 10-Mark Explanation

The necessity for a Virtual Base Class arises during multipath multiple/hybrid inheritance, widely called the Diamond Inheritance Problem. Consider a scenario where Class A is a base class inherited by two child classes, Class B and Class C. Now, a fourth class, Class D, inherits from both Class B and Class C via multiple inheritance.

Without virtual inheritance, Class B receives a copy of Class A's data members, and Class C also receives a copy of Class A's data members. Consequently, when Class D inherits from both B and C, it gets two separate copies of Class A's data members. This duplication causes two severe issues:

  1. Ambiguity: When an object of Class D attempts to access a variable inherited from Class A, the C++ compiler cannot decide which path's variable to access (B's copy or C's copy), resulting in a compile-time error.
  2. Memory Wastage: Storing redundant copies of identical data members wastes system memory unnecessarily.

The Diamond Problem Diagram

Class A (Base)
↙ ↘
Class B (virtual)
Class C (virtual)
↘ ↙
Class D (Child)

Solution using Virtual Base Class: By placing the keyword virtual during the inheritance declaration of intermediate classes (B and C), C++ ensures that only one shared single copy of the top-level base class (A) is passed down to any subsequent derived classes (D), completely resolving ambiguity and eliminating duplicate data allocation.

C++ Example Program

Virtual_Base_Class.cpp
#include <iostream>
using namespace std;

class Student {
public:
    int rollNumber;
    void setRoll(int r) { rollNumber = r; }
};

// Declaring Student as Virtual Base Class
class Academic : virtual public Student {
public:
    float marks;
};

// Declaring Student as Virtual Base Class
class Sports : virtual public Student {
public:
    float score;
};

// Result inherits single copy of Student via Academic and Sports
class Result : public Academic, public Sports {
public:
    void displayTotal() {
        // No ambiguity accessing rollNumber here
        cout << "Roll Number: " << rollNumber << endl;
        cout << "Total Score: " << (marks + score) << endl;
    }
};

int main() {
    Result studentResult;
    studentResult.setRoll(101); // Ambiguity resolved!
    studentResult.marks = 85.5;
    studentResult.score = 90.0;
    studentResult.displayTotal();
    return 0;
}

4. Abstract Classes

⚡ Quick Exam Answer (2–5 Marks)

Definition: An Abstract Class in C++ is a class designed specifically to serve as a base class and cannot be instantiated directly into objects. A class becomes abstract when it contains at least one Pure Virtual Function.

Detailed 10-Mark Explanation

In object-oriented design, abstraction is the principle of hiding internal implementation details while displaying only relevant interfaces to the outside world. An abstract class acts as a blueprint or contract for derived classes. It outlines what functions a child class must implement, without specifying how those functions should be implemented.

Rules governing Abstract Classes:

  • An abstract class cannot be instantiated (i.g., you cannot write AbstractClass obj;).
  • It must contain at least one pure virtual function (declared with = 0).
  • If a derived class fails to override all pure virtual functions inherited from an abstract base class, that derived class itself becomes an abstract class.
  • Pointers and references of an abstract class type can be legally created to achieve runtime polymorphism.

C++ Example Program

Abstract_Class.cpp
#include <iostream>
using namespace std;

// Abstract Base Class
class Shape {
public:
    // Pure Virtual Function
    virtual void draw() = 0; 
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "Drawing a Circle." << endl;
    }
};

class Rectangle : public Shape {
public:
    void draw() override {
        cout << "Drawing a Rectangle." << endl;
    }
};

int main() {
    // Shape s; // ERROR! Cannot instantiate abstract class
    Shape* shapePtr;
    Circle c;
    Rectangle r;

    shapePtr = &c;
    shapePtr->draw(); // Output: Drawing a Circle.

    shapePtr = &r;
    shapePtr->draw(); // Output: Drawing a Rectangle.

    return 0;
}

5 & 6. Member Classes & Nesting of Classes

⚡ Quick Exam Answer (2–5 Marks)

Nested Class: A class declared inside the scope of another enclosing class. It helps group logically related classes together and prevents namespace pollution.

Member Class (Containment/Composition): An object of one class declared as a data member inside another class. Represents a HAS-A relationship.

Detailed 10-Mark Explanation

While inheritance represents an IS-A relationship (e.g., Dog IS-A Animal), modern Object-Oriented design frequently utilizes composition, which represents a HAS-A relationship (e.g., Car HAS-A Engine). In C++, this can be achieved using Member Classes or Nested Classes.

1. Member Class (Containment): When a class uses an instance/object of another class as its internal attribute, the embedded object is referred to as a member class object. For example, a Car class holding an object of an Engine class as its private member.

2. Nested Class: A nested class is defined entirely inside the declaration body of an outer class. A nested class is enclosed in the scope of the outer class. Outer class access rules apply: if a nested class is placed under the private section of the outer class, it remains accessible only within the outer class. If placed under public, outside code can instantiate it using the scope resolution operator: Outer::Nested obj;.

C++ Example: Nested Class & Composition

Nested_Class_Example.cpp
#include <iostream>
using namespace std;

class Computer {
public:
    // Nested Class definition
    class CPU {
    public:
        void process() {
            cout << "CPU processing instructions..." << endl;
        }
    };

    void startComputer() {
        processor.process();
    }

private:
    CPU processor; // Member class instance (Composition)
};

int main() {
    Computer myPC;
    myPC.startComputer();

    // Accessing public nested class directly using scope resolution
    Computer::CPU standaloneCPU;
    standaloneCPU.process();

    return 0;
}

SECTION B — POLYMORPHISM

7. Meaning and Concept of Polymorphism

⚡ Quick Exam Answer (2–5 Marks)

Definition: Polymorphism is derived from Greek words (Poly = Many, Morphs = Forms). It allows a single operator, function, or interface to display different behaviors depending on the context or operational data type.

Detailed 10-Mark Explanation

Polymorphism allows C++ programs to process objects differently depending on their class type or data inputs through a single unified interface. It reduces code complexity and enables dynamic system extensibility.

Polymorphism is broadly categorized into two major types in C++:

  1. Compile-time Polymorphism (Static / Early Binding): The specific function code to execute is determined by the compiler at compile time based on signatures and parameters. It executes faster because no lookup delay occurs at runtime. Achieved through Function Overloading and Operator Overloading.
  2. Runtime Polymorphism (Dynamic / Late Binding): The exact function call resolution is deferred until the application is actively executing. It relies on Base Class Pointers and Virtual Functions. Although slightly slower due to vtable lookups, it offers immense flexibility.

8. Pointers Fundamentals

⚡ Quick Exam Answer (2–5 Marks)

Pointer: A variable that stores the memory address of another variable rather than a direct value.

Key Operators:

  • & (Address-of operator): Retrieves the memory address of a variable.
  • * (Dereference/Indirection operator): Accesses the value stored at the memory address pointed to by the pointer.

Detailed 10-Mark Explanation

Pointers are fundamental tools in C++ that allow direct manipulation of computer memory. Every variable stored in memory occupies a specific location identified by a unique memory address (typically expressed in hexadecimal). A pointer is declared using the asterisk symbol (*) before its identifier.

C++ Pointer Syntax
int num = 25;
int* ptr = # // ptr stores memory address of num

Advantages of Pointers:

  • Enables dynamic memory allocation in heap memory using new and delete.
  • Allows passing large structures/objects to functions efficiently by reference without copying full data.
  • Required for implementing complex data structures like linked lists, trees, and graphs.
  • Essential for achieving runtime polymorphism via virtual function call lookup.

9. Pointers to Objects

⚡ Quick Exam Answer (2–5 Marks)

Definition: A pointer variable declared to hold the memory address of a class object.

Member Access: Members are accessed using the arrow operator (->) instead of the standard dot operator (.).

Detailed 10-Mark Explanation

Just as pointers can store addresses of primitive data types (int, float), they can store memory addresses of user-defined class instances. Creating pointers to objects allows dynamic object allocation in heap memory during runtime using the new operator.

Difference between Dot Operator (.) and Arrow Operator (->):

  • Use Dot Operator (.) when interacting directly with an object variable: object.memberFunction();
  • Use Arrow Operator (->) when interacting through an object pointer: objectPtr->memberFunction();

C++ Example Program

Pointer_To_Object.cpp
#include <iostream>
using namespace std;

class Box {
private:
    double length;
public:
    Box(double l) : length(l) {}
    void display() {
        cout << "Box Length = " << length << endl;
    }
};

int main() {
    // Dynamic object creation in Heap
    Box* bPtr = new Box(12.5);

    // Invoking function using Arrow Operator
    bPtr->display();

    // Freeing memory
    delete bPtr;
    return 0;
}

10. this Pointer

⚡ Quick Exam Answer (2–5 Marks)

Definition: this is an implicit, hidden pointer available inside all non-static member functions of a class. It holds the memory address of the specific object that invoked the member function.

Detailed 10-Mark Explanation

When a class member function is called, how does C++ know which object's internal variables to modify? C++ automatically passes a hidden pointer named this as an implicit argument to every non-static member function. The this pointer points directly to the invoking object instance.

Primary Applications of this Pointer:

  1. Resolving Naming Conflicts (Shadowing): When function parameter names are identical to class member variable names, this->var explicitly refers to the class member.
  2. Returning Current Object Reference: Used in method chaining (e.g., obj.setX(5).setY(10);) by returning *this.

C++ Example Program

This_Pointer_Example.cpp
#include <iostream>
using namespace std;

class Student {
private:
    int age; // Class member variable

public:
    // Local parameter name matches class member name
    void setAge(int age) {
        // this->age refers to member variable, age refers to parameter
        this->age = age; 
    }

    void display() {
        cout << "Student Age: " << this->age << endl;
    }
};

int main() {
    Student s;
    s.setAge(20);
    s.display();
    return 0;
}

11. Pointers to Derived Classes

⚡ Quick Exam Answer (2–5 Marks)

In C++, a Base Class Pointer can legally point to a Derived Class Object. However, through that base pointer, you can access ONLY the members that were inherited from the Base class (unless Virtual Functions are used).

Detailed 10-Mark Explanation

C++ allows type compatibility between pointers along inheritance hierarchies. A pointer declared of Base Class type is allowed to store the memory address of any child object derived from that Base Class. This is the structural foundation for achieving runtime polymorphism.

Base Pointer - Derived Object Concept
Base* ptr;    // Base pointer
Derived obj;  // Derived object
ptr = &obj;   // Completely Valid in C++!

Key Limitation without Virtual Functions: Even though ptr physically holds the memory address of a Derived object, C++ compiler determines accessible members based on the pointer's declaration type (Base), not the target object's type. Calling overridden functions through ptr will execute the Base class version unless functions are declared with the virtual keyword.

12. Virtual Functions

⚡ Quick Exam Answer (2–5 Marks)

Definition: A member function in a base class declared using the keyword virtual. It instructs the compiler to perform dynamic/late binding, ensuring that when called via a Base class pointer, the derived class version of the function is executed based on the actual object being pointed to.

Detailed 10-Mark Explanation

Virtual functions enable Runtime Polymorphism in C++. By default, C++ uses early static binding, resolving function calls during compilation based on the pointer type. By prefixing a base class member function with the virtual keyword, you tell the compiler to override early binding and perform late dynamic binding based on the target object at execution time.

How Virtual Functions Work Internally (VTABLE and VPTR):

  • VTABLE (Virtual Table): The compiler creates a static array table of function pointers for every class that contains or inherits virtual functions.
  • VPTR (Virtual Pointer): Every object created from a class containing virtual functions automatically gets a hidden pointer member (vptr) that points directly to the corresponding VTABLE of that class.
  • At runtime, calling a virtual function causes C++ to follow the object's VPTR to its class VTABLE, executing the correct derived function implementation.

C++ Example: Normal vs Virtual Function Execution

Virtual_Function_Demo.cpp
#include <iostream>
using namespace std;

class Base {
public:
    void displayNormal() { cout << "Base Normal Display" << endl; }
    virtual void displayVirtual() { cout << "Base Virtual Display" << endl; }
};

class Derived : public Base {
public:
    void displayNormal() { cout << "Derived Normal Display" << endl; }
    void displayVirtual() override { cout << "Derived Virtual Display" << endl; }
};

int main() {
    Base* ptr;
    Derived obj;
    ptr = &obj;

    // Static Early Binding calls Base version
    ptr->displayNormal();  // Output: Base Normal Display

    // Dynamic Late Binding calls Derived version!
    ptr->displayVirtual(); // Output: Derived Virtual Display

    return 0;
}

13. Pure Virtual Functions

⚡ Quick Exam Answer (2–5 Marks)

Definition: A virtual function in a base class that has no definition/body within that base class and is declared by assigning = 0.

Syntax: virtual void functionName() = 0;

Detailed 10-Mark Explanation

A pure virtual function is used when a base class represents an abstract concept where a default implementation cannot logically exist. For example, a generalized Shape class cannot provide a meaningful implementation for calculateArea() because area formulas depend entirely on specific geometries like Circle or Triangle.

By declaring virtual void calculateArea() = 0; inside Shape, you mandate that every derived class must explicitly implement its own version of this function. Any class containing a pure virtual function automatically becomes an Abstract Class.

14. Function Overloading

⚡ Quick Exam Answer (2–5 Marks)

Definition: Declaring multiple functions in the same scope with the exact same name but with different parameter lists (different number, types, or order of arguments). Represents Compile-Time Polymorphism.

Detailed 10-Mark Explanation

Function overloading enhances readability by allowing developers to use a single intuitive name for operations that perform functionally identical tasks on differing data types (e.g., adding two integers vs adding two floating-point numbers).

Rules for Overloading Functions:

  • Parameter signatures MUST differ in number of arguments, data types of arguments, or order of argument types.
  • Changing ONLY the function return type is NOT valid overloading and will cause compile errors.

C++ Example Program

Function_Overloading.cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    // 1. Adds two integers
    int add(int a, int b) { return a + b; }

    // 2. Overloaded: Adds three integers
    int add(int a, int b, int c) { return a + b + c; }

    // 3. Overloaded: Adds two double values
    double add(double a, double b) { return a + b; }
};

int main() {
    Calculator calc;
    cout << calc.add(5, 10) << endl;        // Calls version 1
    cout << calc.add(5, 10, 15) << endl;    // Calls version 2
    cout << calc.add(2.5, 3.7) << endl;     // Calls version 3
    return 0;
}

15. Operator Overloading

⚡ Quick Exam Answer (2–5 Marks)

Definition: Giving additional customized functionality to standard C++ operators (like +, -, <<) so they can operate directly on user-defined types/objects.

Detailed 10-Mark Explanation

By default, built-in C++ operators work exclusively with native primitive types like int or float. If you attempt to add two objects using c3 = c1 + c2;, the compiler throws an error. Operator overloading allows developers to redefine operator actions for custom objects, making complex data structures intuitive to manipulate.

Operators that CANNOT be Overloaded in C++:

  • Scope Resolution Operator (::)
  • Member Selection Operator (.)
  • Member Pointer Selector (.*)
  • Ternary Conditional Operator (?:)
  • Sizeof Operator (sizeof)

Operator Overloading Approaches: Overloading can be implemented via Member Functions or non-member Friend Functions.

C++ Example: Overloading + Operator (Member Function)

Binary_Operator_Overload.cpp
#include <iostream>
using namespace std;

class Complex {
private:
    float real, imag;
public:
    Complex(float r = 0, float i = 0) : real(r), imag(i) {}

    // Overloading '+' operator as a member function
    Complex operator + (const Complex& obj) {
        Complex temp;
        temp.real = real + obj.real;
        temp.imag = imag + obj.imag;
        return temp;
    }

    void display() {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex c1(3.5, 2.5), c2(1.5, 4.5);
    Complex c3 = c1 + c2; // Executes c1.operator+(c2)
    c3.display();         // Output: 5 + 7i
    return 0;
}

Important Comparison Tables

Mastering comparison tables is critical for scoring top marks in BCA written examinations.

1. Compile-Time vs Runtime Polymorphism

Feature Compile-Time Polymorphism Runtime Polymorphism
Binding Time Early Binding / Static Binding at compile time. Late Binding / Dynamic Binding at runtime.
Implementation Function Overloading & Operator Overloading. Virtual Functions & Function Overriding.
Execution Speed Faster execution (no runtime lookup delay). Slightly slower (VTABLE lookup overhead).
Flexibility Less flexible. Highly flexible and dynamic.

2. Function Overloading vs Function Overriding

Parameter Function Overloading Function Overriding
Class Scope Occurs within the same single class scope. Occurs across two classes (Base & Derived).
Function Signatures MUST be different (parameter types or counts). MUST be identical in name, return, and parameters.
Inheritance Inheritance is NOT required. Inheritance is mandatory.
Binding Resolved at compile-time. Resolved at runtime (requires virtual keyword).

3. Virtual Function vs Pure Virtual Function

Feature Virtual Function Pure Virtual Function
Base Class Body Contains a default definition/body in Base class. Has NO body/definition in Base class (= 0).
Instantiation Base class can be instantiated if no pure virtual exists. Base class CANNOT be instantiated (Abstract).
Derived Class Duty Overriding is optional in derived class. Overriding is mandatory for concrete child classes.

Important Unit–III C++ Programs

Below are full, syntactically correct programs frequently asked in university practical & theory examinations.

Program: Operator Overloading using Friend Function

Friend_Operator_Overload.cpp
#include <iostream>
using namespace std;

class Distance {
private:
    int feet, inches;
public:
    Distance(int f = 0, int i = 0) : feet(f), inches(i) {}

    // Declare Friend Function for '+' operator
    friend Distance operator + (const Distance& d1, const Distance& d2);

    void display() {
        cout << "Feet: " << feet << " Inches: " << inches << endl;
    }
};

// Friend Function definition (takes 2 explicit arguments)
Distance operator + (const Distance& d1, const Distance& d2) {
    Distance temp;
    temp.feet = d1.feet + d2.feet;
    temp.inches = d1.inches + d2.inches;
    if(temp.inches >= 12) {
        temp.feet += temp.inches / 12;
        temp.inches %= 12;
    }
    return temp;
}

int main() {
    Distance dist1(5, 8), dist2(3, 6);
    Distance total = dist1 + dist2; // Invokes operator+(dist1, dist2)
    total.display(); // Output: Feet: 9 Inches: 2
    return 0;
}
