SECTION A: CLASSES AND OBJECTS

Topic 01

Classes and Objects

⚡ Quick Exam Answer (2 - 5 Marks)

Class: A class is a user-defined data type in C++ that encapsulates data members (variables) and member functions (methods) into a single logical unit. It acts as a blueprint or template for creating objects.

Object: An object is an identifiable entity, a real-world instance of a class. When a class is declared, no memory is allocated. Memory is allocated only when an object of that class is instantiated.

📖 Detailed 10-Mark Answer

In Object-Oriented Programming (OOP), procedural paradigms are replaced by entity-centric structures. At the core of this paradigm is the concept of a Class and an Object. A class solves the limitations of primitive C structures by allowing functions to be bundled alongside data. It provides the mechanism for Encapsulation and Data Hiding.

Why Classes and Objects are Required: In traditional structured programming (like C), data moves freely around the system, making it vulnerable to accidental modification by external functions. Classes restrict this unrestricted access. They force interaction with data exclusively through controlled interfaces (public member functions), ensuring data security and software scalability.

Class as a Blueprint vs. Object as an Instance: Consider an architectural blueprint for a building. The blueprint itself contains dimensions, structure, and design, but it has no physical existence and occupies no land. That blueprint represents a Class. The actual physical building constructed according to that blueprint is an Object. You can build multiple distinct buildings (objects) from a single blueprint (class).

Components of a Class:

  • Data Members: These are variables declared inside the class that store the attributes or state of an object.
  • Member Functions: These are functions declared inside or outside the class that define the behavior or operations that can be performed on the object's data members.

Access Specifiers in C++: Access specifiers control the visibility and accessibility of class members from outside the class:

  • private: Members declared as private are accessible only from within member functions of the same class. They are completely hidden from outside functions. This is the default access level in C++.
  • public: Members declared as public can be accessed from anywhere in the program using the object name and the dot (.) operator.
  • protected: Members are accessible within the class and inside derived classes (used in Inheritance). They remain hidden from external standalone functions.
💻 C++ Program Implementation
Program 1.1: Complete Class and Object Example
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    int rollNumber;
    string name;
    float marks;

public:
    // Function to set student details
    void setDetails(int r, string n, float m) {
        rollNumber = r;
        name = n;
        marks = m;
    }

    // Function to display student details
    void displayDetails() {
        cout << "Roll Number : " << rollNumber << endl;
        cout << "Name        : " << name << endl;
        cout << "Marks       : " << marks << endl;
    }
};

int main() {
    // Instantiating objects of class Student
    Student s1, s2;

    // Accessing public member functions using dot operator
    s1.setDetails(101, "Durga Prasad", 92.5);
    s2.setDetails(102, "Aakash Sharma", 88.0);

    cout << "--- Student 1 Details ---" << endl;
    s1.displayDetails();

    cout << "\n--- Student 2 Details ---" << endl;
    s2.displayDetails();

    return 0;
}
🔍 Code Explanation

1. class Student defines a new user-defined data type named Student.
2. Data members rollNumber, name, and marks are placed under private: access level. Direct access like s1.rollNumber = 101; in main() will cause a compile-time error.
3. Functions setDetails() and displayDetails() are under public: specifier, making them accessible via the main function.
4. In main(), Student s1, s2; allocates memory for two distinct instances in the stack memory.
5. s1.setDetails(...) invokes the member function bound specifically to the memory instance of s1.

💡 Important Exam Points
  • Class definition must end with a semicolon (};).
  • By default, all members of a C++ class are private if no access specifier is mentioned.
  • Class is a logical entity; Object is a physical entity that occupies RAM.
Topic 02

Defining Member Functions

⚡ Quick Exam Answer (2 - 5 Marks)

A member function is a function declared inside a class that operates on the data members of that class. Member functions can be defined in two ways:

  1. Inside the class definition: Function body is written inside the class. Automatically treated as inline.
  2. Outside the class definition: Declared inside the class and defined outside using the Scope Resolution Operator (::).
📖 Detailed 10-Mark Answer

Member functions represent the behavioral aspect of an object. They serve as the bridge between the external program environment and the internal private data members of the class. Member functions can take parameters, return values, and manipulate private, protected, or public data members within the same class.

Defining Member Function Inside the Class: When a function is defined directly inside the class body, the C++ compiler automatically attempts to treat it as an inline function. This approach is typically used for short functions containing 1 to 3 lines of code. It eliminates the call overhead, but increases executable binary size if used for large functions.

Defining Member Function Outside the Class: For larger, more complex functions, defining them outside the class keeps the class interface clean and readable. The function is declared inside the class body to inform the compiler about its signature, and its actual implementation is placed outside the class body using the Scope Resolution Operator (::).

Syntax for Outside Definition:

return_type ClassName :: functionName(parameter_list) {
    // Function body
}

The scope resolution operator (::) informs the compiler that the function functionName belongs to the class scope of ClassName, granting it full permission to access private members of that class.

💻 C++ Program Implementation
Program 2.1: Inside vs Outside Member Function Definitions
#include <iostream>
using namespace std;

class Rectangle {
private:
    float length;
    float breadth;

public:
    // Member function defined INSIDE the class definition
    void setDimensions(float l, float b) {
        length = l;
        breadth = b;
    }

    // Declarations for functions defined OUTSIDE the class
    float calculateArea();
    float calculatePerimeter();
};

// Member function defined OUTSIDE class using Scope Resolution Operator
float Rectangle::calculateArea() {
    return length * breadth;
}

float Rectangle::calculatePerimeter() {
    return 2 * (length + breadth);
}

int main() {
    Rectangle rect;
    rect.setDimensions(10.5, 5.0);

    cout << "Area of Rectangle      : " << rect.calculateArea() << endl;
    cout << "Perimeter of Rectangle : " << rect.calculatePerimeter() << endl;

    return 0;
}
💡 Important Exam Points
  • Inside-class function definitions are automatically treated as inline by default.
  • Outside-class definitions must use the scope resolution operator ClassName::, otherwise they are treated as global standalone functions.
  • Function prototype must be declared inside the class before defining it outside.
Topic 03

Making an Outside Function Inline

⚡ Quick Exam Answer (2 - 5 Marks)

An Inline Function is a function for which the compiler expands its execution code directly at the point of call during compilation, rather than issuing a standard function call mechanism. A member function defined outside the class can be explicitly made inline by prefixing its definition header with the keyword inline.

📖 Detailed 10-Mark Answer

The Need for Inline Functions: Standard function calls involve significant runtime overhead. When a function is called, the CPU must save register states, push function arguments onto the stack, jump to the function's memory address, execute code, pop values from stack, and jump back to the calling point. For small functions (e.g., getter/setter methods), the time spent performing this calling overhead is greater than the time required to execute the actual code inside the function.

Inline functions solve this efficiency bottleneck. When a function is declared as inline, the compiler replaces every invocation call site directly with the compiled code of that function, eliminating the execution jump overhead.

Making an Outside Function Inline: While functions defined inside the class are inline by default, functions defined outside the class are non-inline by default. To make an outside function inline, we place the inline keyword explicitly in front of the outside definition.

Syntax:

inline return_type ClassName :: functionName(arguments) {
    // Small body code
}

Limitations of Inline Functions: Inline is a request to the compiler, not a strict command. The compiler will refuse to make a function inline under the following conditions:

  • The function contains loops (for, while, do-while).
  • The function contains static variables.
  • The function is recursive (calls itself).
  • The function contains complex switch or goto statements.
  • The return type is non-void and return statement is missing.
💻 C++ Program Implementation
Program 3.1: Outside Inline Member Function
#include <iostream>
using namespace std;

class Operation {
private:
    int a, b;

public:
    void getValues(int x, int y) {
        a = x;
        b = y;
    }

    // Function declarations inside class
    int add();
    int multiply();
};

// Explicitly making outside member functions INLINE
inline int Operation::add() {
    return a + b;
}

inline int Operation::multiply() {
    return a * b;
}

int main() {
    Operation op;
    op.getValues(12, 5);

    // At compile time, call site is substituted with (a + b) and (a * b)
    cout << "Addition Result       : " << op.add() << endl;
    cout << "Multiplication Result : " << op.multiply() << endl;

    return 0;
}
💡 Important Exam Points
  • Inlining speeds up program execution at the expense of potential memory expansion (code bloat).
  • Place the inline keyword in the definition header outside, or both declaration and definition.
  • Inline functions are ideal for tiny getter and setter methods.
Topic 04

Nested Member Functions

⚡ Quick Exam Answer (2 - 5 Marks)

A member function of a class can call another member function of the same class directly by using its name without using the object name and dot operator. This concept of calling a member function from inside another member function of the same class is called Nesting of Member Functions.

📖 Detailed 10-Mark Answer

In standard Object-Oriented programming execution, member functions are typically invoked from the main() function or external driver code using an object and dot operator (e.g., obj.functionName()). However, inside a class environment, all member functions share the same class scope and have direct implicit visibility to one another.

Why Nesting is Useful: Nesting simplifies caller responsibilities and ensures strict operational sequences. For instance, if a calculation function requires mathematical validation beforehand, calling the validation function inside the calculation function prevents the external caller from forgetting to run validation first. It allows modularization and code reusability within the class execution pipeline.

Syntax & Mechanism:

class Demo {
public:
    void functionOne() {
        // Code for function one
    }

    void functionTwo() {
        // Nesting: Calling functionOne directly without dot operator
        functionOne(); 
        // Additional code
    }
};
💻 C++ Program Implementation
Program 4.1: Nesting of Member Functions
#include <iostream>
using namespace std;

class Numbers {
private:
    int num1, num2;

public:
    void input() {
        cout << "Enter two integers: ";
        cin >> num1 >> num2;
    }

    // Member function to find maximum
    int largest() {
        if (num1 > num2)
            return num1;
        else
            return num2;
    }

    // Member function that nests largest()
    void displayLargest() {
        // Direct call to member function largest() without using object reference
        int maxVal = largest(); 
        cout << "The largest number between " << num1 << " and " << num2 << " is: " << maxVal << endl;
    }
};

int main() {
    Numbers n;
    n.input();
    
    // External driver calls displayLargest(), which internally nests largest()
    n.displayLargest(); 

    return 0;
}
💡 Important Exam Points
  • No dot operator (.) or object reference is required when calling a sibling member function inside the same class.
  • Nesting works seamlessly across public and private member functions within the same class.
Topic 05

Private Member Functions

⚡ Quick Exam Answer (2 - 5 Marks)

A member function declared under the private: access specifier of a class is called a Private Member Function. It cannot be invoked directly from outside the class using an object and dot operator (e.g., obj.privateFunc() will throw a compile error). It can only be called by a public member function belonging to the same class.

📖 Detailed 10-Mark Answer

While data members are routinely placed in private sections for Encapsulation, developers often overlook that functions can also be declared private. Private member functions are an abstraction mechanism designed to hide utility code, validation logic, or internal implementation details that external code should never touch.

Why Private Functions are Used: Consider a Banking Application class Account. The class might have a public function withdrawMoney(). Before dispensing cash, it needs to perform authentication, log transaction histories, and update encryption keys. These internal routines should not be callable by external programmers directly. Placing them inside private member functions ensures they are invoked only at proper execution stages inside public interfaces.

Data Hiding and Encapsulation: Private member functions enforce encapsulation by separating public operational interfaces from internal helper routines. If an internal algorithm changes later, only the private function code changes; external code calling the public function remains entirely unaffected.

💻 C++ Program Implementation
Program 5.1: Private Member Functions Demonstration
#include <iostream>
#include <string>
using namespace std;

class BankAccount {
private:
    string accountHolder;
    double balance;
    int pinNumber;

    // PRIVATE MEMBER FUNCTION: Cannot be called from main()
    bool validatePin(int enteredPin) {
        return (enteredPin == pinNumber);
    }

public:
    void createAccount(string name, double initialBalance, int pin) {
        accountHolder = name;
        balance = initialBalance;
        pinNumber = pin;
    }

    // PUBLIC MEMBER FUNCTION: Invokes private function internally
    void withdraw(double amount, int pin) {
        if (validatePin(pin)) { // Invoking Private Function
            if (amount <= balance) {
                balance -= amount;
                cout << "Withdrawal successful! New balance: $" << balance << endl;
            } else {
                cout << "Error: Insufficient funds!" << endl;
            }
        } else {
            cout << "Security Alert: Invalid PIN number!" << endl;
        }
    }
};

int main() {
    BankAccount user;
    user.createAccount("Durga Prasad", 5000.0, 4321);

    // user.validatePin(4321); // COMPILE ERROR: Cannot access private function directly

    // Valid invocation via public interface
    user.withdraw(1500.0, 4321); // Correct PIN
    user.withdraw(500.0, 0000);  // Wrong PIN

    return 0;
}
💡 Important Exam Points
  • Attempting obj.privateFunction() in main() generates a compiler access error.
  • Private functions provide helper/utility functionality to public member functions.
Topic 06

Arrays within a Class

⚡ Quick Exam Answer (2 - 5 Marks)

Arrays can be declared as data members inside a class. When an array is declared inside a class, every object created from that class gets its own independent set of array memory locations. They are used to manage collections of similar attributes belonging to a single entity (e.g., marks of a student in 5 subjects).

📖 Detailed 10-Mark Answer

In many practical OOP applications, an object contains sets of related data items rather than single primitive values. C++ supports arrays (integer arrays, character strings, floating-point arrays) as member variables inside a class scope.

Declaration and Memory: An array data member is declared inside the class just like a normal variable, but with specified array dimension boundaries (e.g., int marks[5];). When an object of such a class is created, contiguous memory required for the entire array size is allocated directly within that object's instance boundary.

Practical Applications:

  • Storing monthly sales data inside an Employee class instance.
  • Storing test subject scores inside a Student class instance.
  • Managing inventory item codes inside a ShoppingList class instance.
💻 C++ Program Implementation
Program 6.1: Storing and Processing Arrays inside a Class
#include <iostream>
using namespace std;

const int MAX_ITEMS = 5;

class ShoppingCart {
private:
    int itemCode[MAX_ITEMS];
    float itemPrice[MAX_ITEMS];
    int count;

public:
    void initCount() { 
        count = 0; 
    }

    void addItem(int code, float price) {
        if (count < MAX_ITEMS) {
            itemCode[count] = code;
            itemPrice[count] = price;
            count++;
        } else {
            cout << "Cart is full!" << endl;
        }
    }

    void displayTotalValue() {
        float total = 0;
        cout << "\n--- Cart Summary ---" << endl;
        for (int i = 0; i < count; i++) {
            cout << "Item Code: " << itemCode[i] << " | Price: $" << itemPrice[i] << endl;
            total += itemPrice[i];
        }
        cout << "Total Value: $" << total << endl;
    }
};

int main() {
    ShoppingCart cart;
    cart.initCount();

    cart.addItem(1001, 25.50);
    cart.addItem(1002, 12.00);
    cart.addItem(1003, 85.75);

    cart.displayTotalValue();

    return 0;
}
💡 Important Exam Points
  • Each object maintains its own separate copy of array elements.
  • Array index boundaries must be strictly monitored inside member functions to avoid memory overflow errors.
Topic 07

Memory Allocation for Objects

⚡ Quick Exam Answer (2 - 5 Marks)

When a class is defined, zero bytes of memory are allocated for data. Memory allocation happens only when an Object is instantiated. Separate memory space is allocated for non-static data members of every object, whereas Member Functions are allocated memory only once during compilation and shared across all instantiated objects of that class.

📖 Detailed 10-Mark Answer

Understanding memory representation is vital for performance optimization in C++. A common misconception is that memory is created when writing a class. In reality, a class is merely a compiler type specification. RAM is consumed only upon object creation.

Common Code vs. Individual Object Data:

If 100 objects of a class are instantiated, creating 100 duplicate copies of identical member function code would waste memory. C++ optimizes this:

  • Data Member Memory: Allocated separately for each object. Object 1 and Object 2 have completely independent memory locations for storing their respective variables.
  • Member Function Memory: Placed in the Code/Text segment of memory once when the class is compiled. All objects call this single code block. The C++ compiler passes the implicit this pointer to identify which object's data members should be operated upon.
Visual Representation: Memory Distribution for Objects
Object 1 (RAM)

int x = 10;

float y = 20.5;

Object 2 (RAM)

int x = 30;

float y = 40.8;

Shared Function Memory (Text Segment)

void display() { ... }

Shared by Object 1 & Object 2

Stack vs. Dynamic Heap Allocation:

  • Stack Allocation: Created automatically (e.g., Student s1;). Memory is freed automatically when the object goes out of scope.
  • Dynamic Heap Allocation: Allocated manually using the new operator (e.g., Student *s1 = new Student();). Memory remains allocated until explicitly released using the delete operator.
💻 C++ Program Implementation
Program 7.1: Stack vs Dynamic Heap Object Allocation
#include <iostream>
using namespace std;

class Sample {
public:
    int id;
    void show() {
        cout << "Object ID: " << id << " at memory address: " << this << endl;
    }
};

int main() {
    // 1. Stack Allocation (Automatic)
    Sample obj1;
    obj1.id = 1;
    obj1.show();

    Sample obj2;
    obj2.id = 2;
    obj2.show();

    // 2. Heap Allocation (Dynamic)
    Sample *heapObj = new Sample();
    heapObj->id = 3;
    heapObj->show();

    // Free heap memory manually
    delete heapObj; 

    return 0;
}
💡 Important Exam Points
  • Data members take unique memory locations for each object instance.
  • Member functions are loaded into memory once and shared among all instances.
  • sizeof(ClassName) equals the sum of its non-static data members (plus padding bytes for memory alignment).
Topic 08

Static Data Members

⚡ Quick Exam Answer (2 - 5 Marks)

A Static Data Member is a class variable prefixed with the static keyword. Unlike normal data members, only a single copy of a static data member is created for the entire class, and this single copy is shared by all objects of that class. It must be defined outside the class scope.

📖 Detailed 10-Mark Answer

In standard C++ class structures, each object retains its own private copy of variables. However, situations arise where a single state variable must be shared across all objects of a class (for example, counting the total number of active objects in memory or tracking a global interest rate in a banking system).

Characteristics of Static Data Members:

  1. Single Memory Allocation: It is initialized to zero automatically when the first object of its class is created, if no other initialization is present.
  2. Global Class Visibility: It belongs to the class as a whole, rather than any specific object instance.
  3. Outside Definition Requirement: Declaring a static data member inside a class does not allocate memory. Memory must be allocated explicitly outside the class definition in global scope using the Scope Resolution Operator.

Outside Definition Syntax:

dataType ClassName :: staticVariableName = initialValue;
💻 C++ Program Implementation
Program 8.1: Shared Static Data Member for Object Counter
#include <iostream>
using namespace std;

class Item {
private:
    int itemCode;
    // Declaration of static data member inside class
    static int count; 

public:
    void setData(int c) {
        itemCode = c;
        count++; // Incrementing shared counter
    }

    void displayCount() {
        cout << "Item Code: " << itemCode << " | Total Items Created (count): " << count << endl;
    }
};

// MANDATORY: Definition and memory allocation outside class
int Item :: count = 0;

int main() {
    Item i1, i2, i3;

    i1.setData(101);
    i2.setData(102);
    i3.setData(103);

    // All objects reflect the exact same shared count value
    i1.displayCount();
    i2.displayCount();
    i3.displayCount();

    return 0;
}
💡 Important Exam Points
  • Static data members exist in memory even before any object of the class is instantiated.
  • Failure to define a static data member outside the class results in a Linker Error (undefined reference).
Topic 09

Static Member Functions

⚡ Quick Exam Answer (2 - 5 Marks)

A member function declared with the static keyword is a Static Member Function. Key rules:

  • It can access ONLY static data members or other static member functions of the class.
  • It can be called using the class name directly (ClassName::functionName()) without creating an object.
  • It does not have access to the implicit this pointer.
📖 Detailed 10-Mark Answer

Static member functions are designed to operate at the class level rather than the instance level. They act as manager functions for static data members.

Why Static Functions Cannot Access Non-Static Data: Non-static data members require a specific object instance to exist (they depend on the object's this pointer address). Because a static member function can be invoked using the class name when zero objects exist in memory, it has no this pointer. Attempting to access non-static variables inside a static function produces a compile error: "invalid use of member in static member function".

Syntax & Invocation:

// Calling via class name (Recommended)
ClassName::staticFunctionName();

// Calling via object instance
objectName.staticFunctionName();
💻 C++ Program Implementation
Program 9.1: Static Member Function Usage
#include <iostream>
using namespace std;

class StudentCounter {
private:
    int id;
    static int totalStudents; // Static data member

public:
    void setID(int i) {
        id = i;
        totalStudents++;
    }

    // STATIC MEMBER FUNCTION
    static void showTotal() {
        // cout << id; // COMPILE ERROR! Cannot access non-static member 'id'
        cout << "Current Total Enrolled Students: " << totalStudents << endl;
    }
};

// Defining static data member
int StudentCounter::totalStudents = 0;

int main() {
    // Calling static function BEFORE creating any objects
    StudentCounter::showTotal();

    StudentCounter s1, s2;
    s1.setID(501);
    s2.setID(502);

    // Invoking static function via Class Name
    StudentCounter::showTotal();

    return 0;
}
💡 Important Exam Points
  • Static member functions can be called without instantiating an object.
  • They cannot be marked as const or virtual.
  • They cannot access normal (non-static) variables or functions directly.
Topic 10

Arrays of Objects

⚡ Quick Exam Answer (2 - 5 Marks)

An Array of Objects is a collection of multiple object instances stored in contiguous memory under a single identifier name. Just as an array of int stores multiple integers, an array of objects stores multiple instances of a class type. Syntax: ClassName arrayName[size];.

📖 Detailed 10-Mark Answer

When managing datasets representing multiple real-world entities (e.g., 60 students in a classroom, 500 employee records, or 100 inventory items), creating individual object variables like emp1, emp2, emp3... is inefficient and unmaintainable. An array of objects provides an organized structure.

Memory Layout: Declaring Employee emp[50]; allocates a single contiguous block of memory large enough to hold 50 individual Employee objects sequentially. Member functions are accessed by combining the array subscript index with the dot operator: emp[i].getData();.

💻 C++ Program Implementation
Program 10.1: Managing Student Records using Array of Objects
#include <iostream>
#include <string>
using namespace std;

class Manager {
private:
    int empID;
    string name;
    float salary;

public:
    void inputData() {
        cout << "Enter Employee ID: ";
        cin >> empID;
        cout << "Enter Name: ";
        cin >> name;
        cout << "Enter Salary: ";
        cin >> salary;
    }

    void displayData() {
        cout << "ID: " << empID << " | Name: " << name << " | Salary: $" << salary << endl;
    }
};

int main() {
    const int SIZE = 3;
    // Declaring Array of Objects
    Manager team[SIZE]; 

    cout << "=== ENTER DETAILS FOR 3 EMPLOYEES ===" << endl;
    for (int i = 0; i < SIZE; i++) {
        cout << "\nEmployee " << (i + 1) << ":" << endl;
        team[i].inputData();
    }

    cout << "\n=== DISPLAYING ALL EMPLOYEE RECORDS ===" << endl;
    for (int i = 0; i < SIZE; i++) {
        team[i].displayData();
    }

    return 0;
}
💡 Important Exam Points
  • If a class has constructors, declaring an array of objects invokes the default constructor for every element in the array.
  • Array index starts at 0 and goes up to SIZE - 1.
Topic 11

Objects as Function Arguments

⚡ Quick Exam Answer (2 - 5 Marks)

Objects can be passed to functions as parameters in two ways:

  1. Pass by Value: A copy of the object is passed into the function. Changes made inside the function do not affect the original object.
  2. Pass by Reference: The memory address of the object is passed using reference variables (&). Modifications inside the function directly update the caller's original object.
📖 Detailed 10-Mark Answer

Because a class is a user-defined type, object variables behave like built-in types in C++. You can pass objects to standalone functions or to member functions of another object, and functions can also return objects.

1. Pass by Value Mechanics: The system creates a temporary copy of the argument object inside the function parameter using its copy constructor. This guarantees that the original object cannot be altered accidentally, but causes memory and performance overhead for large classes.

2. Pass by Reference Mechanics: An alias of the original object is passed. No secondary copy is created in memory, making execution faster. If read-only security is required during pass by reference, pass it as a const reference parameter: void process(const Complex &obj);.

💻 C++ Program Implementation
Program 11.1: Adding Two Time Duration Objects
#include <iostream>
using namespace std;

class Time {
private:
    int hours;
    int minutes;

public:
    void setTime(int h, int m) {
        hours = h;
        minutes = m;
    }

    void showTime() {
        cout << hours << " Hours and " << minutes << " Minutes." << endl;
    }

    // Object passed by value as arguments
    void sum(Time t1, Time t2) {
        minutes = t1.minutes + t2.minutes;
        hours = t1.hours + t2.hours + (minutes / 60);
        minutes = minutes % 60;
    }
};

int main() {
    Time T1, T2, T3;

    T1.setTime(2, 45); // 2 hrs 45 mins
    T2.setTime(3, 30); // 3 hrs 30 mins

    // T3 calculates total time by receiving T1 and T2 as arguments
    T3.sum(T1, T2);

    cout << "T1: "; T1.showTime();
    cout << "T2: "; T2.showTime();
    cout << "T3 (Sum): "; T3.showTime();

    return 0;
}
💡 Important Exam Points
  • Passing by reference avoids memory overhead caused by copying large objects.
  • Functions can also return objects using standard return syntax: Time result; return result;.
Topic 12

Friend Functions

⚡ Quick Exam Answer (2 - 5 Marks)

A Friend Function is a non-member function that is granted access to the private and protected members of a class. It is declared inside the class using the keyword friend, but defined outside without using any scope resolution operator.

📖 Detailed 10-Mark Answer

One of the foundational rules of Object-Oriented Programming is Data Hiding: external functions cannot access private members of a class. However, situations arise where two independent classes must collaborate closely (for example, comparing private data between a Manager class and a Scientist class, or overloading complex mathematical operators). C++ provides the friend mechanism to handle these cases safely.

Key Characteristics of Friend Functions:

  1. It is not in the scope of the class in which it is declared as friend.
  2. It cannot be called using an object and dot operator (e.g., obj.friendFunc() is invalid). It is invoked like a standard C++ function: friendFunc(obj).
  3. It usually accepts objects of the class as arguments to access their private data members using the dot operator (e.g., obj.privateData).
  4. It can be declared in either the public or private section of the class without changing its access rights.

Friendship is Not Mutual or Transitive: If Class A declares Function F as a friend, Function F can access Class A's private members. But Class A does not automatically gain access to Function F's private data. Friendship must be explicitly granted.

💻 C++ Program Implementation
Program 12.1: Friend Function Bridging Two Private Classes
#include <iostream>
using namespace std;

// Forward declaration of Class B
class ClassB; 

class ClassA {
private:
    int valueA;

public:
    void setValue(int val) { valueA = val; }

    // Declaring Friend Function
    friend void findMax(ClassA objA, ClassB objB); 
};

class ClassB {
private:
    int valueB;

public:
    void setValue(int val) { valueB = val; }

    // Declaring Friend Function
    friend void findMax(ClassA objA, ClassB objB); 
};

// DEFINITION of Friend Function (NO scope resolution :: operator used!)
void findMax(ClassA objA, ClassB objB) {
    // Accessing private members 'valueA' and 'valueB' directly
    if (objA.valueA > objB.valueB) {
        cout << "ClassA has larger value: " << objA.valueA << endl;
    } else {
        cout << "ClassB has larger value: " << objB.valueB << endl;
    }
}

int main() {
    ClassA a;
    ClassB b;

    a.setValue(150);
    b.setValue(280);

    // Calling friend function like a standard global function
    findMax(a, b); 

    return 0;
}
💡 Important Exam Points
  • Friend function definitions do not use the Classname:: scope resolution operator.
  • The friend keyword appears only in the declaration inside the class, not in the outside definition.
  • Friend functions break strict data encapsulation; use them judiciously.

Topic 13

Constructors

⚡ Quick Exam Answer (2 - 5 Marks)

A Constructor is a special member function of a class whose primary purpose is to initialize the data members of an object automatically when that object is instantiated. Key rules:

  • It has the exact same name as its class.
  • It has no return type (not even void).
  • It is executed automatically whenever an object is created.
📖 Detailed 10-Mark Answer

In standard C programming, variables often contain garbage values until explicitly initialized. If an object's variables are uninitialized, executing member operations will lead to unpredictable runtime crashes. A constructor solves this problem by ensuring that every object is created in a valid, initialized state.

Characteristics of Constructors:

  1. They must be declared in the public: access section of a class to allow external object instantiation.
  2. They are invoked automatically by the compiler when memory is allocated for an object.
  3. They cannot return values, so specifying a return type (even void) results in a compilation error.
  4. They can be overloaded (a class can define multiple constructors with different parameter signatures).
  5. They cannot be inherited, though a derived class can invoke a base class constructor.
  6. They cannot be declared virtual or static.

Types of Constructors:

  • Default Constructor: Takes no arguments.
  • Parameterized Constructor: Accepts parameters to initialize objects with custom values.
  • Copy Constructor: Initializes an object using the values of another existing object of the same class.
  • Dynamic Constructor: Allocates memory dynamically at runtime using new inside the constructor.
💻 C++ Program Implementation
Program 13.1: Basic Default Constructor Demonstration
#include <iostream>
using namespace std;

class Point {
private:
    int x, y;

public:
    // DEFAULT CONSTRUCTOR: Same name as Class, No Return Type
    Point() {
        x = 0;
        y = 0;
        cout << "Default Constructor Invoked! Point initialized to (0,0)" << endl;
    }

    void display() {
        cout << "Coordinates: (" << x << ", " << y << ")" << endl;
    }
};

int main() {
    // Constructor triggers automatically upon instantiation
    Point p1; 
    p1.display();

    return 0;
}
💡 Important Exam Points
  • If no user constructor is defined, the C++ compiler automatically generates an implicit default constructor.
  • If a user defines any custom constructor, the compiler suppresses its implicit default constructor.
Topic 14

Parameterized Constructors

⚡ Quick Exam Answer (2 - 5 Marks)

A constructor that accepts parameters/arguments is called a Parameterized Constructor. It enables developers to initialize different objects with distinct initial state values at the exact moment of instantiation.

📖 Detailed 10-Mark Answer

Default constructors initialize every object of a class with identical values. However, real-world applications require objects to hold distinct data upon creation (for instance, creating two bank account objects with different initial balances).

Methods of Invoking Parameterized Constructors:

  1. Implicit Call (Shorthand):
    Complex c1(10, 20);
  2. Explicit Call:
    Complex c1 = Complex(10, 20);

Constructor Overloading: A class can feature both a default constructor and multiple parameterized constructors simultaneously. The compiler selects the appropriate constructor based on the number and type of arguments passed during instantiation.

💻 C++ Program Implementation
Program 14.1: Parameterized Constructor and Overloading
#include <iostream>
using namespace std;

class Account {
private:
    int accountNumber;
    double balance;

public:
    // Default Constructor
    Account() {
        accountNumber = 0;
        balance = 0.0;
    }

    // PARAMETERIZED CONSTRUCTOR
    Account(int accNum, double initialBal) {
        accountNumber = accNum;
        balance = initialBal;
    }

    void display() {
        cout << "Acc No: " << accountNumber << " | Balance: $" << balance << endl;
    }
};

int main() {
    Account acc1; // Calls Default Constructor
    Account acc2(1001, 5500.75); // Calls Parameterized Constructor (Implicit)
    Account acc3 = Account(1002, 9200.00); // Calls Parameterized Constructor (Explicit)

    acc1.display();
    acc2.display();
    acc3.display();

    return 0;
}
💡 Important Exam Points
  • Providing explicit constructor parameters eliminates the need for extra initialization functions like setData().
  • When using parameterized constructors, ensure a default constructor is defined if arrays of objects will be instantiated.
Topic 15

Constructors with Default Arguments

⚡ Quick Exam Answer (2 - 5 Marks)

Like normal functions, constructor parameters can specify default values. A constructor that provides default values for one or more of its parameters is called a Constructor with Default Arguments. It allows objects to be instantiated with or without arguments.

📖 Detailed 10-Mark Answer

Constructors with default arguments combine the flexibility of default constructors and parameterized constructors into a single declaration.

Rules for Default Arguments:

  • Default values must be specified starting from the rightmost parameter inward. You cannot leave gaps (e.g., void func(int a = 10, int b) is invalid).
  • Avoid Ambiguity Errors: Defining both a default constructor (Box()) and a constructor where all parameters have default values (Box(int l = 1, int b = 1)) creates a compiler error on Box b1; because the compiler cannot determine which constructor to invoke.
💻 C++ Program Implementation
Program 15.1: Constructor with Default Arguments
#include <iostream>
using namespace std;

class Box {
private:
    int length, width, height;

public:
    // Constructor with default arguments (height defaults to 10, width defaults to 5)
    Box(int l, int w = 5, int h = 10) {
        length = l;
        width = w;
        height = h;
    }

    int calculateVolume() {
        return length * width * height;
    }
};

int main() {
    Box b1(2);       // Uses length=2, width=5 (default), height=10 (default) -> Vol = 100
    Box b2(2, 4);    // Uses length=2, width=4, height=10 (default) -> Vol = 80
    Box b3(2, 4, 6); // Overrides all default arguments -> Vol = 48

    cout << "Volume Box 1: " << b1.calculateVolume() << endl;
    cout << "Volume Box 2: " << b2.calculateVolume() << endl;
    cout << "Volume Box 3: " << b3.calculateVolume() << endl;

    return 0;
}
💡 Important Exam Points
  • Default parameters reduce code duplication across overloaded constructors.
  • Default argument values must be provided right-to-left without skipping positions.
Topic 16

Dynamic Initialization of Objects

⚡ Quick Exam Answer (2 - 5 Marks)

Dynamic Initialization refers to initializing an object's data members at runtime using dynamic values (e.g., user input or variable calculations) rather than hardcoded compile-time constants. This is achieved by overloading constructors with different argument types.

📖 Detailed 10-Mark Answer

In many real-world applications, initial object values cannot be known when writing the code. Values may depend on user input, file reads, or complex calculations at runtime. Dynamic initialization allows C++ applications to select and execute different constructors based on runtime data inputs.

Key Application Scenario: A fixed-deposit banking application where interest can be supplied either as an integer percentage rate (e.g., 9%) or as a fractional floating-point rate (e.g., 0.09). Overloading constructors allows the system to construct the object correctly based on the runtime format provided by the user.

💻 C++ Program Implementation
Program 16.1: Dynamic Initialization of Fixed Deposit Object
#include <iostream>
using namespace std;

class FixedDeposit {
private:
    long int principal;
    int years;
    float rate;
    float returnAmount;

public:
    FixedDeposit() {}

    // Constructor 1: Rate as fractional float (e.g., 0.08)
    FixedDeposit(long int p, int y, float r) {
        principal = p;
        years = y;
        rate = r;
        returnAmount = principal;
        for (int i = 1; i <= y; i++)
            returnAmount *= (1.0 + rate);
    }

    // Constructor 2: Rate as percentage integer (e.g., 8)
    FixedDeposit(long int p, int y, int r) {
        principal = p;
        years = y;
        rate = float(r) / 100.0;
        returnAmount = principal;
        for (int i = 1; i <= y; i++)
            returnAmount *= (1.0 + rate);
    }

    void display() {
        cout << "Principal: $" << principal << " | Maturity Value: $" << returnAmount << endl;
    }
};

int main() {
    long int p;
    int y, R;
    float r;

    cout << "Enter Principal, Years, and Rate (as fraction, e.g., 0.08): ";
    cin >> p >> y >> r;
    // Object initialized dynamically at runtime using floating point rate
    FixedDeposit fd1(p, y, r); 

    cout << "Enter Principal, Years, and Rate (as integer %, e.g., 8): ";
    cin >> p >> y >> R;
    // Object initialized dynamically at runtime using integer rate
    FixedDeposit fd2(p, y, R); 

    fd1.display();
    fd2.display();

    return 0;
}
💡 Important Exam Points
  • Dynamic initialization binds data to objects using runtime user input.
  • Overloaded constructors evaluate parameter types at runtime to select the correct constructor.
Topic 17

Copy Constructor

⚡ Quick Exam Answer (2 - 5 Marks)

A Copy Constructor is a member function that initializes a new object using the values of an existing object of the same class. Syntax: ClassName (const ClassName &obj). The parameter must be passed by reference using the & symbol.

📖 Detailed 10-Mark Answer

A copy constructor is invoked whenever an object is initialized using another existing object of the same class type.

When is a Copy Constructor Invoked?

  1. When an object is explicitly initialized from another object: Student s2 = s1; or Student s2(s1);.
  2. When an object is passed by value to a function.
  3. When a function returns an object by value.

Why Pass Parameter by Reference?
The signature must be ClassName(const ClassName &obj). If you attempt to pass the object by value (ClassName(ClassName obj)), passing the parameter would itself require creating a copy, which would invoke the copy constructor again. This creates an infinite recursion loop until the call stack overflows. Passing by reference avoids this loop.

Shallow Copy vs. Deep Copy:

  • Shallow Copy: The default copy constructor performs a bitwise, field-by-field copy. If the class contains raw heap pointer members (e.g., int *ptr;), both objects will end up pointing to the exact same memory address. Deallocating memory in one object leaves the second object with a dangling pointer, leading to double-free runtime errors.
  • Deep Copy: A user-defined copy constructor allocates new, independent heap memory for the destination object and copies the underlying values, ensuring complete independence between objects.
💻 C++ Program Implementation
Program 17.1: User-Defined Deep Copy Constructor
#include <iostream>
using namespace std;

class Sample {
private:
    int id;

public:
    // Normal Parameterized Constructor
    Sample(int i) {
        id = i;
    }

    // USER-DEFINED COPY CONSTRUCTOR
    Sample(const Sample &obj) {
        id = obj.id; // Copying data value from source object
        cout << "Copy Constructor Invoked!" << endl;
    }

    void display() {
        cout << "ID Value: " << id << endl;
    }
};

int main() {
    Sample s1(100); // Calls Parameterized Constructor
    
    Sample s2 = s1; // Calls Copy Constructor implicitly
    Sample s3(s1);  // Calls Copy Constructor explicitly

    cout << "s1: "; s1.display();
    cout << "s2: "; s2.display();
    cout << "s3: "; s3.display();

    return 0;
}
💡 Important Exam Points
  • The copy constructor parameter must use reference pass (&) to prevent infinite recursion.
  • Use const in the reference parameter to prevent the copy constructor from accidentally modifying the source object.
  • Deep copying is essential for classes that manage dynamic pointer memory.
Topic 18

Dynamic Constructors

⚡ Quick Exam Answer (2 - 5 Marks)

When memory allocation for class data members is performed dynamically at runtime inside a constructor using the new operator, the constructor is called a Dynamic Constructor. It enables objects to request exact RAM sizing on demand.

📖 Detailed 10-Mark Answer

Static member array allocations (e.g., char name[100];) waste memory if only a few bytes are used, or overflow if the input exceeds array bounds. A dynamic constructor solves this by allocating the exact required memory on the heap at runtime using pointers and the new operator.

Object Lifecycle with Dynamic Allocation:

Constructor (new) ➔ Object Usage ➔ Destructor (delete)

Memory allocated by a dynamic constructor inside the heap is not released automatically when the object goes out of scope. A custom Destructor must be implemented to explicitly release heap memory using the delete operator.

💻 C++ Program Implementation
Program 18.1: Dynamic Constructor allocating String Memory
#include <iostream>
#include <cstring>
using namespace std;

class StringManager {
private:
    char *name; // Pointer data member

public:
    // DYNAMIC CONSTRUCTOR
    StringManager(const char *s) {
        int length = strlen(s);
        name = new char[length + 1]; // Dynamically allocating memory on Heap
        strcpy(name, s);
    }

    // DESTRUCTOR releasing dynamic heap allocation
    ~StringManager() {
        delete[] name; // Releasing allocated heap memory
        cout << "Heap memory freed by Destructor." << endl;
    }

    void display() {
        cout << "Stored String: " << name << endl;
    }
};

int main() {
    // Dynamic constructor allocates exact memory required for string length
    StringManager str1("Durga Prasad Mishra - BCA C++ Unit II");
    str1.display();

    return 0; // Destructor executes automatically upon exiting scope
}
💡 Important Exam Points
  • Dynamic constructors allocate heap memory using the new operator.
  • Every class with a dynamic constructor must include a destructor with delete to prevent memory leaks.
Topic 19

Destructors

⚡ Quick Exam Answer (2 - 5 Marks)

A Destructor is a special member function that is automatically executed when an object goes out of scope or is explicitly deleted. Its purpose is to release resources (like heap memory or open file handles) allocated by the object. Syntax: ~ClassName().

📖 Detailed 10-Mark Answer

Destructors clean up resources before an object is removed from memory, preventing resource leaks in long-running software applications.

Characteristics of Destructors:

  1. It has the exact same name as its class, prefixed with a tilde (~).
  2. It takes no arguments and has no return type (not even void).
  3. A class can have only ONE destructor (destructors cannot be overloaded).
  4. It is invoked automatically in reverse order of object construction.
  5. It cannot be declared static or const.

Order of Execution: When objects are created in stack memory, they are constructed in sequence (1, 2, 3). When the enclosing block ends, destructors run in reverse order (3, 2, 1) following Last-In, First-Out (LIFO) stack order.

💻 C++ Program Implementation
Program 19.1: Constructor and Destructor Execution Sequence
#include <iostream>
using namespace std;

int globalCount = 0;

class LifeCycle {
public:
    LifeCycle() {
        globalCount++;
        cout << "Constructor Invoked! Object ID: " << globalCount << endl;
    }

    // DESTRUCTOR
    ~LifeCycle() {
        cout << "Destructor Invoked! Destroying Object ID: " << globalCount << endl;
        globalCount--;
    }
};

int main() {
    cout << "--- Entering Main ---" << endl;
    LifeCycle obj1;
    LifeCycle obj2;

    {
        cout << "--- Entering Local Block ---" << endl;
        LifeCycle obj3;
        cout << "--- Exiting Local Block ---" << endl;
    } // obj3 goes out of scope here and its destructor is called immediately

    cout << "--- Exiting Main ---" << endl;
    return 0; // obj2 and obj1 destructors run in reverse order of creation
}
💡 Important Exam Points
  • Destructors cannot accept arguments, so they cannot be overloaded.
  • Destructors execute automatically in reverse order (LIFO) of constructor execution.
  • For objects created using new, the destructor runs only when delete is explicitly called.

Program 2: Swapping Private Data of Two Classes using Friend Function

Problem Statement: Write a C++ program to swap the private data values of two distinct classes using a common friend function.

#include <iostream>
using namespace std;

class Class_2; // Forward declaration

class Class_1 {
private:
    int value1;

public:
    void setData(int val) { value1 = val; }
    void display() { cout << "Value 1 = " << value1 << endl; }
    friend void swapValues(Class_1 &c1, Class_2 &c2);
};

class Class_2 {
private:
    int value2;

public:
    void setData(int val) { value2 = val; }
    void display() { cout << "Value 2 = " << value2 << endl; }
    friend void swapValues(Class_1 &c1, Class_2 &c2);
};

// Friend function passing parameters by REFERENCE to swap original values
void swapValues(Class_1 &c1, Class_2 &c2) {
    int temp = c1.value1;
    c1.value1 = c2.value2;
    c2.value2 = temp;
}

int main() {
    Class_1 obj1;
    Class_2 obj2;

    obj1.setData(100);
    obj2.setData(500);

    cout << "=== BEFORE SWAPPING ===" << endl;
    obj1.display();
    obj2.display();

    swapValues(obj1, obj2);

    cout << "\n=== AFTER SWAPPING ===" << endl;
    obj1.display();
    obj2.display();

    return 0;
}
