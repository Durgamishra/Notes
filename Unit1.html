01 Introduction to Programming & C

1. Simple Definition

A programming language is a formalized set of instructions, rules, and syntax used by human programmers to communicate with a computer system and instruct it to perform specific computational tasks, solve mathematical calculations, or manage data operations.

2. Detailed Explanation

Computers inherently understand only binary digits—sequences of 0s and 1s representing high and low electronic voltage states. Because human thought process is abstract and expressed in natural languages, writing complex applications directly in machine language is tedious, error-prone, and inefficient. Programming languages act as a bridge between human logic and computer hardware.

Programming languages have evolved through distinct generations: Machine Language (1st Generation), Assembly Language (2nd Generation), and High-Level Languages (3rd Generation and beyond). High-level languages abstract hardware complexities, allowing developers to write instructions using English-like syntax and mathematical expressions.

Category Machine Language Assembly Language High-Level Language (e.g., C)
Syntax Binary digits (0s and 1s) Mnemonic codes (ADD, MOV) English-like keywords (`if`, `while`)
Execution Speed Extremely Fast (Direct CPU) Fast (Minimal translation) Requires Compilation / Translation
Portability Non-portable (Machine specific) Non-portable (Architecture specific) Highly Portable across processors
Error Debugging Extremely Difficult Difficult Easy and structured

Compiler vs. Interpreter

To execute high-level programs, code must be translated into machine instructions. This is done via two distinct language processors:

  • Compiler: Translates the entire source code into machine code in one go, generating an intermediate object/executable file. Execution speed is high. C, C++, and Rust use compilers.
  • Interpreter: Translates and executes the source code line-by-line. If an error occurs, execution stops immediately at that line. Debugging is easier, but execution speed is slower. Python and JavaScript use interpreters.

History and Origin of C Language

The C programming language was developed between 1969 and 1972 by Dennis Ritchie at AT&T Bell Laboratories in Murray Hill, New Jersey. C was created primarily to implement the UNIX operating system. It evolved from older languages: ALGOL 60 → CPL → BCPL (developed by Martin Richards) → B (developed by Ken Thompson) → C (Dennis Ritchie).

In 1989, the American National Standards Institute (ANSI) standardized C (known as ANSI C or C89), ensuring uniform execution across different computing systems worldwide.

Key Characteristics of C

  • Middle-Level Language: Combines the structural clarity of high-level languages with low-level direct access to hardware and memory addresses (via pointers).
  • Structured Language: Supports function modularity, block structures, and control flow primitives.
  • Portability: C programs written for one machine can be compiled and executed on other architectures with minimal changes.
  • Extensibility: Users can write custom functions and add them to standard software library suites.

02 Keywords & Identifiers

1. Simple Definition

Keywords are reserved words that have predefined, fixed meanings to the C compiler and cannot be redefined. Identifiers are custom names given by programmers to program elements such as variables, functions, arrays, structures, and labels.

2. Detailed Explanation

In the C language token system, every word processed by the compiler is classified as a keyword, identifier, constant, string literal, symbol, or operator. Keywords form the structural syntax of the language (e.g., controlling loops, defining types, specifying storage). Because the compiler relies on these words to parse logic, they cannot be used as user-defined variable names.

Identifiers, on the other hand, are created by the programmer. Constructing valid identifiers requires strict adherence to lexical rules enforced by the compiler during lexical analysis.

The 32 Standard ANSI C Keywords

Category Reserved Keywords
Data Types char, int, float, double, void
Type Modifiers signed, unsigned, short, long
Control Flow if, else, switch, case, default, break, continue, goto
Looping Primitives for, while, do
Storage Classes auto, register, static, extern
Derived/User-Defined struct, union, enum, typedef
Qualifiers & Misc const, volatile, sizeof, return

Rules for Naming Identifiers

  1. An identifier can consist of upper and lower case letters (A-Z, a-z), digits (0-9), and the underscore character (_).
  2. The first character must be a letter or an underscore. It cannot begin with a digit.
  3. C is strictly case-sensitive: TotalMarks, totalmarks, and TOTALMARKS are three distinct identifiers.
  4. No reserved keyword can be used as an identifier name (e.g., int float; is illegal).
  5. No special characters, spaces, or punctuation symbols (such as @, $, %, -) are allowed within an identifier.
  6. Identifier length is implementation-dependent, but ANSI C guarantees recognition of at least the first 31 characters.

03 Constants

1. Simple Definition

A constant (also called a literal) is a fixed value assigned to a program element that cannot be altered or modified by the program during execution.

2. Detailed Types of Constants

  • Integer Constants: Whole numerical quantities without fractional components.
    • Decimal: Digits 0–9 without leading zero (e.g., 150, -45).
    • Octal: Digits 0–7 preceded by a leading zero 0 (e.g., 025 = 21 in decimal).
    • Hexadecimal: Digits 0–9 and letters A–F, preceded by 0x or 0X (e.g., 0x1A = 26 in decimal).
  • Real / Floating-Point Constants: Numbers containing fractional components or exponential expressions.
    • Fractional Notation: 3.14159, -0.005
    • Scientific Exponential Notation: 1.5e3 (represents 1.5 × 103 = 1500.0).
  • Character Constants: A single character enclosed within single quotes (e.g., 'A', '9', '$'). Internally, C converts them to ASCII integer codes (e.g., 'A' = 65).
  • String Constants: A sequence of zero or more characters enclosed within double quotes (e.g., "Hello BCA", "123"). C appends a hidden null character '\0' to signal the end of string memory.

Escape Sequences in C

An escape sequence is a non-printable or special character combination beginning with a backslash (\) used to handle formatting within strings and character constants.

Ready-to-Write 5-Mark Exam Answer: Methods of Defining Constants

In C, constants can be defined using two primary methods:

  1. Preprocessor Directive (#define): Replaces occurrences of a symbol with a value before compilation begins.
    Syntax: #define NAME value
    Advantage: Takes no RAM memory space at runtime.
  2. Type Qualifier (const Keyword): Declares a variable as read-only, enforced by the compiler.
    Syntax: const data_type variable_name = value;
    Advantage: Respects type checking and variable scope rules.

04 Variables

1. Simple Definition

A variable is a named location in memory used to store data that can be read, changed, or updated during program execution.

2. Variable Phases: Declaration, Initialization, Assignment

Phase Definition C Code Example
Declaration Tells compiler the variable name and reserves appropriate data type memory. int salary;
Initialization First-time value assignment given during declaration. int salary = 50000;
Assignment Updating or changing an existing variable's value later in code execution. salary = 55000;

Variable Scope: Local vs. Global

  • Local Variables: Declared inside a function or block {}. They are accessible only within that block, created on block entry, and destroyed on exit.
  • Global Variables: Declared outside all functions at the top of the file. Accessible by any function in the program throughout its entire lifecycle.
scope_demo.c 
#include <stdio.h>

int global_counter = 100; // Global Variable

void display() {
    int local_var = 10;   // Local Variable inside display()
    printf("Global: %d, Local: %d\n", global_counter, local_var);
}

int main() {
    display();
    // printf("%d", local_var); // ERROR: local_var is out of scope!
    return 0;
}

05 Input and Output Operations

1. Formatted I/O Functions: printf() and scanf()

C relies on standard library routines defined in <stdio.h> to manage stream operations:

  • printf(): Standard formatted output routine that sends styled data to stdout (the console screen). It returns the total count of printed characters.
  • scanf(): Standard formatted input routine that reads characters from stdin (keyboard input), converts them according to format specifiers, and stores them in memory locations passed via address pointers (&). It returns the count of successfully matched and assigned items.

Role of Address Operator (&) in scanf

The & symbol is the address-of operator in C. When passing variables to scanf(), passing just the name passes the variable's value, whereas passing &variable_name provides the memory address where scanf() must write the value read from the keyboard.

Critical Exception: Strings and Arrays

Arrays and String variables (e.g., char name[20];) naturally decay into pointers representing their starting base memory address. Therefore, using & when reading strings in scanf("%s", name); is redundant and incorrect syntax!

Unformatted I/O Functions

  • getchar(): Reads a single character from keyboard entry.
  • putchar(ch): Displays a single character to the console.
  • fgets(str, size, stdin): Safely reads a complete line of text including spaces from standard input, preventing buffer overflow issues associated with older routines like gets().
  • puts(str): Writes a string to the console and automatically appends a newline character.
io_demo.c 
#include <stdio.h>

int main() {
    int age;
    float gpa;
    char grade;

    printf("Enter Age, GPA, and Grade Letter: ");
    // Address operator & passes memory addresses to scanf
    scanf("%d %f %c", &age, &gpa, &grade);

    printf("\n--- Student Info ---\n");
    printf("Age: %d | GPA: %.2f | Grade: %c\n", age, gpa, grade);

    return 0;
}

06 Compilation and Pre-processing Pipeline

1. Simple Definition

The compilation process in C transforms human-readable C source code (.c) into machine-executable binary files (.exe or a.out) through a multi-stage translation pipeline consisting of four primary phases: Preprocessor, Compiler, Assembler, and Linker.

2. Visual Compilation Pipeline Diagram

1
Source Code File (`main.c`) Human-readable high-level code written by developer.
2
Preprocessor (`main.i`) Expands macros (`#define`), includes header files (`#include`), and strips comments.
3
Compiler (`main.s`) Translates expanded C code into architecture-specific Assembly instructions.
4
Assembler (`main.o` or `main.obj`) Converts Assembly instructions into binary Object Code containing machine instructions.
5
Linker (`main.exe` / `a.out`) Merges object files with system library code routines (e.g., standard `printf` binary).
6
Loader & CPU Execution Loads final binary executable into RAM memory for CPU instruction execution.

Preprocessor Directives Explained

Preprocessor directives begin with a hash symbol (#) and are executed before actual code compilation begins:

  • #include <stdio.h>: Search system library paths for standard header declarations.
  • #include "myheader.h": Search current local project directory for user-defined header files.
  • #define SIZE 100: Macro definition replacing all occurrences of SIZE with token 100.
  • #ifdef, #ifndef, #endif: Conditional compilation blocks used to include or skip code sections based on build flags.
Ready-to-Write 10-Mark Exam Answer: Complete C Compilation Pipeline

1. Introduction: C uses a compiled build chain model where source code is systematically processed through multiple distinct software components before execution.

2. Detailed Stages:

  • Stage 1: Preprocessing Phase: The preprocessor takes file.c and generates file.i. It strips out human comments, includes code from header files specified in #include directives, and expands macro definition blocks (#define).
  • Stage 2: Compilation Phase: The compiler accepts expanded source file.i, performs lexical, syntax, and semantic analysis, and translates the logic into architecture-specific Assembly code (file.s). Syntax errors are raised at this step.
  • Stage 3: Assembly Phase: The assembler translates assembly instructions in file.s into binary machine language relocatable object code (file.o or file.obj).
  • Stage 4: Linking Phase: The linker resolves reference addresses across multiple object files and external C libraries (like libc). It binds implementation code for library routines (e.g., printf) and produces the finalized standalone binary executable (file.exe).
  • Stage 5: Loading Phase: When invoked, the operating system's Loader component copies the executable file from secondary storage into RAM memory, sets up register stacks, and transfers control to the main() entry point.

Data types specify how much memory to allocate for a variable, the format of bits stored, and the range of operations that can be performed on it.

Data Type Modifiers

Modifiers alter the size or sign boundary range of primary data types:

  • signed: Uses 1 bit to store the sign (+/-); default setting for numeric types.
  • unsigned: Removes negative ranges, using all bits for positive magnitude, effectively doubling the positive upper limit.
  • short: Decreases storage size (typically 2 bytes for short int).
  • long: Increases storage size (typically 8 bytes for long long int).

Data Type Qualifiers

  • const: Makes variable value read-only; attempts to modify it trigger compile-time errors.
  • volatile: Informs the compiler that a variable's value may be changed by external hardware or concurrent threads, disabling aggressive compiler caching optimizations.
  • restrict: A pointer qualifier indicating that no other pointer accesses the same underlying memory block, enabling performance optimizations.

08 Memory Representation

1. Simple Definition

Memory representation refers to how the C compiler and underlying system hardware store data values as binary bit patterns (0s and 1s) inside RAM byte cells located at specific memory addresses.

2. Detailed Memory Architecture

Computer memory (RAM) is structured as an array of byte cells, where each 1 Byte = 8 Bits. Every byte cell has a unique hexadecimal address pointer (e.g., 0x7ffd1000).

0x7ffd1000
00010100
age = 20
0x7ffd1001
01000001
ch = 'A'

Signed Integer Representation: Two's Complement

Unsigned integers are stored using direct binary conversion. Signed integers use Two's Complement notation to represent negative numbers.

Step-by-Step Example: Storing -5 in an 8-bit Signed Memory Byte
  1. Write positive 5 in binary: 0000 0101
  2. Invert all bits (One's Complement): 1111 1010
  3. Add 1 bit to the result (Two's Complement):
    1111 1010 + 1 = 1111 1011
  4. Result: 1111 1011 represents -5 in memory. The leftmost Bit (MSB = 1) serves as the sign indicator for negative values.

Character Representation (ASCII)

Characters are stored in 1 byte of memory using their numeric ASCII codes. For example, when declaring char grade = 'A';, the binary representation of ASCII code 65 (01000001) is written to that memory byte cell.

09 Operators

1. Simple Definition

An operator is a special symbol that instructs the C compiler to perform specific mathematical, logical, relational, or bitwise manipulations on one or more data values called operands.

Classification by Number of Operands

Category Operands Required Operators Included Example
Unary Operators 1 Operand ++, --, sizeof, !, ~, Unary - x++, -a, sizeof(int)
Binary Operators 2 Operands +, -, *, /, %, &&, ||, &, |, == a + b, x > y
Ternary Operator 3 Operands Conditional Operator ? : (a > b) ? a : b

Exhaustive Operator Categories

1. Arithmetic Operators

Used to perform standard mathematical calculations: Addition (+), Subtraction (-), Multiplication (*), Division (/), and Modulus (%).

Exam Rule: Modulus Operator Restriction

The modulus remainder operator % works only on integer operands (e.g., 10 % 3 = 1). Using floating-point values (e.g., 10.5 % 3.0) causes a compile-time syntax error!

2. Relational Operators

Used to compare two values. They evaluate to boolean integer truth values: 1 for True, and 0 for False. Symbols include: == (Equal to), != (Not equal to), >, <, >=, <=.

3. Logical Operators & Short-Circuit Evaluation

Combines multiple relational test expressions: Logical AND (&&), Logical OR (||), and Logical NOT (!).

  • A && B: Returns 1 only if BOTH operands are true. If A evaluates to 0, B is not evaluated at all (Short-Circuiting).
  • A || B: Returns 1 if AT LEAST ONE operand is true. If A evaluates to 1, B is skipped completely.

4. Bitwise Operators (Step-by-Step Binary Example)

Bitwise operators work directly on the individual bits of integer operands.

^Bitwise XOR1 if bits are different5 ^ 3 = 0110 (Decimal 6)

5. Increment and Decrement Operators: Pre vs. Post

  • Pre-Increment (++x): Increments the value of x by 1 first, then returns the updated value in the surrounding expression.
  • Post-Increment (x++): Evaluates the current value of x in the expression first, then increments x by 1 afterwards.
increment_demo.c 
#include <stdio.h>

int main() {
    int a = 5, b = 5;
    int res1 = ++a; // Pre: 'a' becomes 6, res1 receives 6
    int res2 = b++; // Post: res2 receives 5, then 'b' becomes 6

    printf("Pre-inc: res1 = %d, a = %d\n", res1, a);
    printf("Post-inc: res2 = %d, b = %d\n", res2, b);
    return 0;
}

10 Expressions, Precedence & Associativity

1. Simple Definitions

An expression is a valid combination of operands, operators, and function calls that evaluates to a single scalar value.

Operator Precedence determines the relative evaluation order when multiple distinct operators appear in the same unparenthesized expression. Associativity defines the execution direction (Left-to-Right or Right-to-Left) when operators of equal precedence appear together.

Step-by-Step Expression Evaluation Example

Evaluate: x = 10 + 2 * 6 / 3 - 4
  1. Level 3 Multiplicative operators have higher precedence than additive ones. Left-to-right associativity applies:
    First evaluate 2 * 6 = 12. Expression becomes: 10 + 12 / 3 - 4
  2. Next evaluate division: 12 / 3 = 4. Expression becomes: 10 + 4 - 4
  3. Level 4 Additive operators evaluate Left-to-Right:
    First addition: 10 + 4 = 14. Expression becomes: 14 - 4
  4. Subtraction: 14 - 4 = 10.
  5. Final Assignment (Level 14): Stores 10 into variable x.

Dennis Ritchie / Bell Labs C was developed in 1972 to write UNIX operating system.
32 Keywords Always written in lowercase; cannot be used as variable identifiers.
Preprocessor Directives Lines starting with # processed before code compilation.
Modulus % Operator Returns integer remainder. Only works with integer data types!
Signed Representation Stored in RAM using Two's Complement (Invert bits + Add 1).
Logical Short-Circuiting In &&, if 1st term is 0, 2nd is skipped. In ||, if 1st term is 1, 2nd is skipped.

Last 30 Minutes Before Exam Checklist

  • ✔ Check that main() is spelled in lowercase.
  • ✔ Ensure every execution statement ends with a semicolon ;.
  • ✔ Verify that scanf() variables have the address operator & (except string arrays!).
  • ✔ Remember that float uses %f while double uses %lf format specifier.
  • ✔ Check precedence: Parentheses () are highest; Assignment operators = are right-to-left.
  • ✔ Double check escape sequence directions: backslash \n and NOT forward slash /n.
