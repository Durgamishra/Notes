1. POINTERS: MEMORY BASICS

What is a Memory Address?

To fully understand pointers, one must first understand how computer memory (RAM) is structured. Computer memory is organized as a sequential array of small storage units called bytes. Each byte in memory has a unique numerical identifier known as its Memory Address.

When you declare a variable in C, the compiler allocates a specific number of contiguous bytes in memory based on the variable's data type. For instance, on a standard 32-bit/64-bit architecture, an int typically occupies 4 bytes, a char occupies 1 byte, and a double occupies 8 bytes.

Variable: x
10
Address: 0x7ffd1000

Conceptual Representation: Variable x holding value 10 stored at memory address 0x7ffd1000.

Three essential attributes are associated with every variable:

  • Name of the Variable: An identifier used in code to refer to the value (e.g., x).
  • Value of the Variable: The actual data stored inside the memory cell (e.g., 10).
  • Address of the Variable: The physical/virtual RAM location where the first byte of data starts (e.g., 1000 or 0x7ffd1000).
Important Academic Concept

Addresses are generated dynamically by the Operating System during execution. Therefore, memory addresses change from one run of a program to another. However, inside a single execution run, a variable's address remains fixed.

CONCEPT OF POINTER

A Pointer is a special variable in C that does not store a normal data value (like an integer or character); instead, it stores the memory address of another variable.

Why are Pointers Needed?

Pointers are one of the most powerful features of C programming. They are essential because they allow:

  • Direct manipulation of computer memory locations.
  • Dynamic memory allocation (heap management using malloc, calloc).
  • Efficient handling of large arrays, structures, and strings without making copies.
  • Implementation of dynamic data structures such as linked lists, stacks, queues, and trees.
  • Call-by-reference mechanics in functions to allow returning multiple values or modifying caller variables.

Operators Used with Pointers

  1. Address-of Operator (&): A unary operator that returns the memory address of its operand.
  2. Dereference / Indirection Operator (*): A unary operator that accesses or manipulates the value stored at the memory location contained inside the pointer.

BRIEF EXAM ANSWER (5 MARKS): Concept of Pointer

Definition: A pointer is a variable that stores the memory address of another variable of a specific data type.

Explanation: In C, variables are stored in memory addresses. The address-of operator (&) extracts a variable's memory address, while the dereference operator (*) accesses the value stored at that address. Pointers enable call-by-reference, dynamic memory allocation, and efficient array traversal.

Example:

int x = 10;
int *p = &x; // p holds address 1000
printf("%d", *p); // prints 10
LONG EXAM ANSWER (10 MARKS): Complete Pointer Fundamentals

Introduction: In C, memory management is performed directly. A pointer is a derived data type designed to hold the memory address of another variable.

Core Components:

  • Pointer Declaration: Uses the syntax data_type *pointer_name;
  • Address Assignment: Uses the address-of operator p = &x;
  • Dereferencing: Uses the dereference operator *p to read or write value at address p.

Working Mechanism: Assume variable int a = 25 is allocated at memory location 5000. When we execute int *ptr = &a;, the value stored inside ptr becomes 5000. When *ptr is evaluated, the CPU looks up memory address 5000 and retrieves the value 25.

Advantages of Pointers:

  1. Enables call-by-reference function parameter passing.
  2. Allows efficient dynamic memory allocation at runtime.
  3. Reduces program execution time by avoiding variable copying.
  4. Facilitates building complex data structures like linked lists and binary trees.

Conclusion: Pointers provide high-level C code with near assembly-level memory access, making C exceptionally fast and suitable for system programming.

POINTER DECLARATION & INITIALIZATION

Declaring Pointer Variables

Before using a pointer, it must be declared. The syntax specifies what type of variable the pointer will point to.

Syntax: data_type *pointer_name;

int *ip;    // Pointer to an integer
char *cp;   // Pointer to a character
float *fp;  // Pointer to a floating-point number
double *dp; // Pointer to a double-precision float
Crucial Concept: Size of a Pointer

Regardless of the base data type (char, int, float, double), all pointers in a given system architecture have the exact same size because they all store memory addresses! On a 32-bit system, every pointer is 4 bytes; on a 64-bit system, every pointer is 8 bytes.

Initialization of Pointer Variables

Initialization is the process of assigning the memory address of an existing variable to a declared pointer variable.

int quantity = 100;
int *ptr;          // Declaration
ptr = &quantity;   // Initialization (assigning address of quantity to ptr)

// Combined Declaration and Initialization:
int *ptr2 = &quantity;
Common Mistake: Assigning Arbitrary Addresses

Never assign an arbitrary integer constant directly to a pointer variable (e.g., int *p = 1000;). This attempts to point to absolute memory location 1000, which usually belongs to the Operating System or another protected process, causing immediate program termination via Segmentation Fault!

ACCESSING & DEREFERENCING POINTERS

Once a pointer is initialized with a variable's address, you can access or modify that variable's value through the pointer using the dereference operator (*).

Example Code Demonstration

#include <stdio.h>

int main() {
    int x = 20;
    int *p = &x;

    printf("Value of x directly: %d\n", x);          // Output: 20
    printf("Address of x (&x): %p\n", (void*)&x);    // Output: Address like 0x7ffe...
    printf("Value stored in p: %p\n", (void*)p);      // Output: Same address as &x
    printf("Value pointed to by p (*p): %d\n", *p);  // Output: 20

    // Modifying value of x through pointer p
    *p = 50; 
    printf("New value of x after *p = 50: %d\n", x); // Output: 50

    return 0;
}

Step-by-Step Explanation:

  1. int x = 20; allocates 4 bytes in RAM, places 20 inside, and associates identifier x.
  2. int *p = &x; allocates memory for pointer p and stores the address of x inside p.
  3. *p tells the compiler: "Go to the address stored in p and fetch the integer value stored there."
  4. *p = 50; tells the compiler: "Go to the address stored in p and replace whatever is inside with 50."

NULL POINTER

Definition

A NULL Pointer is a pointer that points to nothing (or memory address zero). It is a standard macro defined in header files like <stdio.h>, <stddef.h>, and <stdlib.h> as ((void *)0).

Purpose

  • To initialize a pointer variable when it has not been assigned any valid memory address yet.
  • To check whether dynamic memory allocation functions (like malloc) succeeded or failed.
  • To indicate the end of dynamic data structures such as Linked Lists (e.g., head->next = NULL;).

Code Example

#include <stdio.h>

int main() {
    int *ptr = NULL; // Initialized to NULL

    if (ptr != NULL) {
        printf("Value at ptr: %d\n", *ptr);
    } else {
        printf("Pointer is NULL. Cannot dereference safely!\n");
    }

    return 0;
}
Critical Safety Rule

Attempting to dereference a NULL pointer (e.g., printf("%d", *ptr); when ptr == NULL) causes an immediate Segmentation Fault (Crash).

WILD POINTER

Definition

A Wild Pointer is an uninitialized pointer variable that contains garbage memory address values.

Why is it Dangerous?

Because an uninitialized pointer contains random garbage data, it points to an arbitrary, unpredictable address in memory. If you attempt to dereference a wild pointer and write to it, you may corrupt critical program data or cause a crash.

Example & Prevention

int main() {
    int *p; // WILD POINTER! Uninitialized, contains garbage address.
    
    // *p = 100; // EXTREMELY DANGEROUS! Memory corruption risk.

    // Prevention: Always initialize to NULL or a valid address immediately!
    int *safe_p = NULL; 
}

DANGLING POINTER

Definition

A Dangling Pointer is a pointer that continues to point to a memory location that has already been deallocated, freed, or destroyed.

How Dangling Pointers Occur

  1. Deallocating memory without resetting pointer: Freeing dynamic memory using free(ptr) without setting ptr = NULL;.
  2. Returning address of local variable: Returning the address of an automatic local variable from a function. When the function finishes execution, its stack frame is destroyed, rendering the address invalid.

Example of Dangling Pointer

#include <stdio.h>
#include <stdlib.h>

int* getLocalAddress() {
    int temp = 50;
    return &temp; // DANGER: Returning address of local variable!
}

int main() {
    // Cause 1: Function returning local variable address
    int *ptr = getLocalAddress(); // ptr is now a Dangling Pointer!

    // Cause 2: Deallocated dynamic memory
    int *dyn_ptr = (int*) malloc(sizeof(int));
    *dyn_ptr = 100;
    free(dyn_ptr); // Memory freed!
    // dyn_ptr is now a Dangling Pointer!

    // Prevention:
    dyn_ptr = NULL; // Safe!
    return 0;
}

GENERIC POINTER (void *)

Definition

A Generic Pointer (or void *) is a special pointer type in C that can hold the memory address of any variable, regardless of its data type (int, float, char, or custom structs).

Key Characteristics

  • Can accept any address without explicit type casting: void *ptr = &x;
  • Cannot be dereferenced directly! Standard C does not know the size of data pointed to by void *. It must be explicitly typecast first.
  • Pointer arithmetic cannot be directly performed on void * in strict standard ANSI C.

Code Example

#include <stdio.h>

int main() {
    int a = 10;
    float b = 3.14f;
    void *ptr; // Generic pointer

    ptr = &a; // Stores int address
    // printf("%d", *ptr); // ERROR! Direct dereferencing prohibited.
    printf("Int value: %d\n", *( (int*)ptr ) ); // Correct using Typecast!

    ptr = &b; // Stores float address
    printf("Float value: %.2f\n", *( (float*)ptr ) ); // Correct using Typecast!

    return 0;
}

POINTER EXPRESSIONS

Pointer expressions combine pointer variables, addresses, arithmetic operators, and dereferencing operators. Understanding precedence is critical for university examinations.

Operator Precedence Comparison

Expression Execution Order / Meaning Resulting Behavior
*p++ Dereference p first, then increment pointer p address. Returns value at original address, then p moves to next memory cell.
*++p Increment pointer p address first, then dereference. Advances address first, then returns value at new location.
(*p)++ Dereference p first, then increment the value stored at that location. Increments the actual integer/data value; address of p stays unchanged.
++*p Pre-increments the value stored at address p. Adds 1 to value stored at address first; address stays unchanged.

POINTER ARITHMETIC

Pointer arithmetic differs fundamentally from ordinary arithmetic. When you add or subtract an integer to/from a pointer, the pointer address advances or retreats by a factor scaled by the size of the data type it points to!

Pointer Arithmetic Formula

New_Address = Current_Address + (N * sizeof(data_type))

Valid Pointer Operations

  • Adding an integer to a pointer: p + 2
  • Subtracting an integer from a pointer: p - 1
  • Incrementing / Decrementing a pointer: p++, p--
  • Subtracting two pointers pointing to elements of the same array: p2 - p1 (returns element count, not byte count).
  • Comparing two pointers using relational operators (==, !=, <, >).

Invalid Pointer Operations

  • Adding two pointers together (p1 + p2 → ILLEGAL!).
  • Multiplying or Dividing pointers (p1 * p2, p1 / 2 → ILLEGAL!).
  • Bitwise operations on pointers (p1 & p2 → ILLEGAL!).

POINTER REPRESENTATION OF ARRAY

In C, the name of an array acts as a constant pointer pointing to the memory address of its first element (index 0). Thus, arr is equivalent to &arr[0].

Equivalence Rule

For any array arr and index i:

arr[i] ≡ *(arr + i)

&arr[i] ≡ (arr + i)

#include <stdio.h>

int main() {
    int arr[3] = {10, 20, 30};
    int *p = arr; // Same as p = &arr[0]

    for (int i = 0; i < 3; i++) {
        printf("Index %d: arr[%d] = %d, *(p + %d) = %d\n", i, i, arr[i], i, *(p + i));
    }
    return 0;
}

ARRAY OF POINTERS

Definition

An Array of Pointers is an array whose individual elements are pointer variables that store memory addresses of other variables or arrays.

Declaration

data_type *array_name[size];

Example: int *ptr[5]; declares an array of 5 integer pointers.

Code Example

#include <stdio.h>

int main() {
    int a = 10, b = 20, c = 30;
    int *arr[3] = {&a, &b, &c}; // Array storing addresses

    for(int i = 0; i < 3; i++) {
        printf("Value %d: %d\n", i + 1, *arr[i]); // Dereferencing individual pointers
    }
    return 0;
}

ACCESSING STRINGS USING POINTERS

In C, a string is a null-terminated ('\0') sequence of characters stored in contiguous memory. A character pointer (char *) can be used to navigate through a string efficiently.

#include <stdio.h>

int main() {
    char str[] = "UNIVERSITY";
    char *ptr = str; // Points to first char 'U'

    printf("Traversing string using pointer: ");
    while (*ptr != '\0') {
        printf("%c ", *ptr);
        ptr++; // Advance pointer to next character
    }
    printf("\n");
    return 0;
}

2. FUNCTIONS

What is a Function?

A Function is a self-contained block of code designed to perform a specific task. Functions divide a large program into smaller, modular components, adhering to the software engineering principle of "Divide and Conquer".

Why Functions are Used

  • Code Reusability: Write once, invoke multiple times without rewriting code.
  • Modularity: Breaks complex tasks into manageable sub-problems.
  • Debugging Ease: Isolates errors inside specific function scopes.
  • Readability & Maintainability: Makes code cleaner and structured.

TYPES OF FUNCTIONS

1. Library Functions

Pre-defined built-in functions provided by C standard header files (e.g., printf(), scanf() in <stdio.h>, strlen() in <string.h>, sqrt() in <math.h>).

2. User-Defined Functions (UDF)

Functions created by programmers to solve specific user requirements.

Four Categories of User-Defined Functions based on Arguments & Return Values:

  1. No Arguments, No Return Value: Functions that perform self-contained I/O operations without accepting caller inputs or returning values.
  2. Arguments Passed, No Return Value: Functions that receive caller data but print or process results internally without returning.
  3. No Arguments Passed, Returns a Value: Functions that collect input internally and compute a return value for the caller.
  4. Arguments Passed, Returns a Value: The ideal functional programming pattern; accepts inputs, computes, and returns the result.

FUNCTION DECLARATION, DEFINITION & CALL

Working with functions involves three major elements:

1. Function Declaration (Prototype)

Informs the compiler about the function name, parameter types, and return type before it is invoked.

Syntax: return_type function_name(type1, type2);

Example: int addNumbers(int, int);

2. Function Definition

Contains the actual body of executable statements executed when the function is called.

int addNumbers(int a, int b) {
    int sum = a + b;
    return sum; // Return statement
}

3. Function Call

Transfers control from caller (e.g., main()) to the called function.

Example: int result = addNumbers(10, 20);

Function Execution Control Flow

main() → (Calls function) → addNumbers() Execution → (Return statement) → Back to main()

RECURSIVE FUNCTIONS

Definition

A Recursive Function is a function that calls itself directly or indirectly to solve a problem by breaking it down into smaller sub-problems of the same type.

Essential Components of Recursion

  1. Base Condition: A terminating condition that stops recursion. Without a base condition, the function calls itself infinitely, exhausting stack memory and causing Stack Overflow.
  2. Recursive Step: The statement where the function invokes itself with updated, smaller arguments moving closer to the base condition.
#include <stdio.h>

// Recursive Factorial Function
long factorial(int n) {
    if (n <= 1) return 1; // BASE CONDITION
    return n * factorial(n - 1); // RECURSIVE STEP
}

int main() {
    printf("Factorial of 4 = %ld\n", factorial(4)); // Output: 24
    return 0;
}

Call Stack Execution Trace for factorial(4):

  • factorial(4) → 4 * factorial(3)
  • factorial(3) → 3 * factorial(2)
  • factorial(2) → 2 * factorial(1)
  • factorial(1) → returns 1 (Base Case Hit!)
  • Unwinding: 2 * 1 = 2 → 3 * 2 = 6 → 4 * 6 = 24.

DYNAMIC MEMORY MANAGEMENT

Static memory allocation fixes variable sizes at compile time (stored in Stack/Data segments). Dynamic Memory Allocation (DMA) allocates memory at runtime from the Heap Segment as required by the program.

Header File Required

#include <stdlib.h>

Core Dynamic Memory Functions

1. malloc() - Memory Allocation

  • Allocates a single contiguous block of memory of requested byte size.
  • Contains garbage values initially.
  • Returns void * address on success, or NULL on failure.
  • Syntax: ptr = (cast_type*) malloc(byte_size);

2. calloc() - Contiguous Allocation

  • Allocates multiple blocks of memory.
  • Initializes all bytes automatically to ZERO!
  • Syntax: ptr = (cast_type*) calloc(num_elements, element_size);

3. realloc() - Re-allocation

  • Resizes previously allocated dynamic memory without losing existing data.
  • Syntax: ptr = (cast_type*) realloc(ptr, new_byte_size);

4. free() - Memory Deallocation

  • Releases dynamically allocated heap memory back to the OS to prevent Memory Leaks.
  • Syntax: free(ptr); ptr = NULL;

STRING HANDLING FUNCTIONS (<string.h>)

1. strlen(str)

Calculates and returns the length of a string excluding the null terminator '\0'.

Example: strlen("Hello") returns 5.

2. strcmp(str1, str2)

Compares two strings lexicographically character by character based on ASCII values.

  • Returns 0 if str1 == str2.
  • Returns < 0 if str1 < str2 ASCII-wise.
  • Returns > 0 if str1 > str2 ASCII-wise.

3. strcpy(dest, src)

Copies source string src (including null character) into destination array dest.

4. strncpy(dest, src, n)

Copies at most n characters from src to dest. Safer than strcpy because it guards against buffer overflow.

5. strcat(dest, src)

Appends (concatenates) source string src to the end of destination string dest.

6. strstr(main_str, sub_str)

Searches for first occurrence of substring sub_str inside main_str. Returns pointer to first matching character, or NULL if not found.

3. STORAGE CLASSES

A Storage Class in C defines four essential attributes of a variable:

  1. Storage Location: Where the variable is stored (RAM CPU Stack, RAM Heap, Data Segment, or CPU Register).
  2. Initial Default Value: Garbage value or Zero (0).
  3. Scope: Visibility region of variable (Block scope, Function scope, File/Global scope).
  4. Lifetime (Storage Duration): How long the variable retains its existence and value in memory.

auto STORAGE CLASS

  • Keyword: auto
  • Default Storage: CPU RAM Memory (Stack).
  • Default Initial Value: Garbage Value.
  • Scope: Local / Block Scope (visible only within declaring block { }).
  • Lifetime: Till execution control remains inside declaring block.

register STORAGE CLASS

  • Keyword: register
  • Default Storage: CPU Registers (High-speed hardware memory inside CPU microprocessor).
  • Default Initial Value: Garbage Value.
  • Scope: Local to block.
  • Lifetime: Till block execution finishes.
Important Rule for register Variables

You CANNOT use the address-of operator (&) on a register variable (e.g., ®_var is ILLEGAL!), because CPU registers do not reside in RAM and do not have RAM memory addresses!

static STORAGE CLASS

  • Keyword: static
  • Default Storage: RAM Data Segment.
  • Default Initial Value: Zero (0).
  • Scope: Local to block (for static local) OR File scope (for static global).
  • Lifetime: Entire program execution lifetime! Retains values between function calls.
#include <stdio.h>

void countCalls() {
    static int count = 0; // Initialized ONLY ONCE at program startup!
    count++;
    printf("Function called %d time(s)\n", count);
}

int main() {
    countCalls(); // Output: 1
    countCalls(); // Output: 2
    countCalls(); // Output: 3
    return 0;
}

extern STORAGE CLASS

  • Keyword: extern
  • Default Storage: RAM Data Segment.
  • Default Initial Value: Zero (0).
  • Scope: Global / File Scope across multiple C translation unit source files.
  • Lifetime: Entire program execution duration.

SCOPE RULES & LINKAGE

1. Block Scope

Variables declared inside braces { } are accessible only within those braces.

2. File Scope (Global Scope)

Variables declared outside all functions are visible to all functions below their declaration in that file.

Variable Shadowing

When a local variable shares the exact same name as a global variable, the local variable shadows (overrides) the global variable within its local block scope.

27 IMPORTANT C PROGRAMS

Program 1: Swap Two Numbers Using Pointers (Call-by-Reference)

#include <stdio.h>

// Function prototype taking integer pointers
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before Swap: x = %d, y = %d\n", x, y);
    
    // Passing memory addresses
    swap(&x, &y);
    
    printf("After Swap:  x = %d, y = %d\n", x, y);
    return 0;
}

Program 2: Find Sum of Array Elements Using Pointer Arithmetic

#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int *ptr = arr; // Points to arr[0]
    int sum = 0;

    for(int i = 0; i < 5; i++) {
        sum += *ptr; // Add value at current pointer location
        ptr++;       // Move pointer to next element
    }

    printf("Sum of Array Elements = %d\n", sum); // Output: 150
    return 0;
}

Program 3: Dynamic Array Allocation using malloc()

#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 5;
    int *arr = (int*) malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Memory Allocation Failed!\n");
        return 1;
    }

    // Populate array
    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * 10;
    }

    printf("Dynamically Allocated Array: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);   // Free heap memory
    arr = NULL;  // Avoid dangling pointer
    return 0;
}

Q: Differentiate between Call by Value and Call by Reference.

Call by Value: Copies actual argument values to formal parameters. Changes inside the called function do not affect caller variables.

Call by Reference: Passes memory addresses of arguments using pointers. Changes inside the function directly modify caller variables.
