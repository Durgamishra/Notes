STRUCTURES IN C

1. Simple Definition

A Structure in C is a user-defined composite data type that allows grouping together variables of different data types under a single unified name. Unlike arrays which store homogeneous elements (elements of the same type), structures store heterogeneous elements (elements of different types).

2. Detailed Explanation

In computer programming, real-world entities rarely consist of a single primitive data type (like a single integer or float). For instance, representing a student requires an integer for roll number, a character array (string) for name, and a floating-point number for GPA/marks. Storing these attributes in separate, disconnected variables quickly becomes unmanageable as the number of entities increases. A structure provides a template or blueprint that encapsulates related variables into a single cohesive logical entity, stored in contiguous memory locations.

3. Why Structures are Needed & Problem with Separate Variables

Consider storing information for 100 students without structures. You would need to declare 100 integer variables for roll numbers, 100 string arrays for names, and 100 float variables for marks:

C Source
int roll1, roll2, roll3, ... roll100;
char name1[50], name2[50], name3[50], ... name100[50];
float marks1, marks2, marks3, ... marks100;

This approach has catastrophic flaws: there is no logical link between roll1, name1, and marks1; passing student data to functions requires passing scores of independent variables; and sorting or processing records becomes virtually impossible. Structures solve this cleanly by binding these distinct attributes together.

4. How Structures Work

When a structure is declared, the C compiler allocates contiguous blocks of memory sufficient to hold all of its individual member variables. The size of the structure is at least the sum of the sizes of its members (subject to memory alignment padding rules enforced by the architecture).

5. Real-World Examples

  • Student Entity: Roll Number (int), Name (char[]), Marks (float), Grade (char).
  • Employee Entity: ID (int), Name (char[]), Salary (double), Department (char[]).
  • Book Entity: ISBN (long), Title (char[]), Author (char[]), Price (float).
  • Product Entity: Product Code (int), Description (char[]), Stock Quantity (int), Unit Price (float).

BRIEF EXAM ANSWER (2–5 Marks): What is a Structure in C?

Answer: A structure in C is a user-defined data type created using the struct keyword that allows grouping variables of different data types into a single unit. It is used to represent real-world entities containing multiple attributes, such as a Student or Employee.
Key Points:
1. Holds heterogeneous data elements.
2. Members are stored in contiguous memory locations.
3. Members are accessed using the dot operator (.) for variables or structure pointer operator (->) for pointers.
Example Syntax:
struct Student { int roll; char name[20]; float marks; };

LONG EXAM ANSWER (8–10 Marks): Explain Structures in C with Need, Memory Representation, and Comparison

Introduction: In procedural programming with C, primitive types are insufficient for real-world modeling. Structures bridge this gap by enabling user-defined custom types.

Definition: A structure is a user-defined heterogeneous data structure declared via struct that encapsulates multiple variables under one identifier.

Need & Advantage: Without structures, managing multi-attribute entities requires maintaining independent parallel arrays or isolated variables, creating code that is error-prone and hard to maintain. Structures group logical attributes, enabling modular code, clean function parameter passing, and structured memory layout.

Working & Memory Layout: The compiler allocates contiguous memory equal to or greater than the sum of individual members. Memory alignment padding may be inserted by compilers to align member addresses with word boundaries for performance.

Conclusion: Structures form the bedrock for advanced C programming concepts including dynamic data structures (linked lists, trees) and file storage records.

DEFINING A STRUCTURE

1. Definition & Theory

Defining a structure creates a new data type template. It specifies the structure tag (name) and lists the member variables along with their data types. Crucially, defining a structure does NOT allocate memory. Memory is allocated only when structure variables are declared.

2. Syntax

Syntax
struct structure_name
{
    data_type member1;
    data_type member2;
    ...
    data_type memberN;
};

3. Line-by-Line Breakdown Example

C Structure Definition
struct Student
{
    int roll;        // Line 1: Integer member for Roll Number
    char name[50];   // Line 2: Character array member for Name
    float marks;     // Line 3: Floating-point member for Marks
};                   // Line 4: Semicolon is MANDATORY ending structure definition

CRITICAL EXAM WARNING: The Missing Semicolon

A very common mistake in C university exams is forgetting the terminating semicolon (;) after the closing brace of a structure definition. In C, omitting this semicolon causes compilation errors, as the compiler expects variable declarations immediately following the closing brace.

DECLARING STRUCTURE VARIABLES

Structure variables can be declared in two primary ways: after the structure definition or along with the structure definition.

Method 1: Declaring After Definition (Standard Approach)

C Source
struct Student
{
    int roll;
    char name[50];
    float marks;
};

// Declaring variables inside main or functions
struct Student s1, s2; // Memory allocated HERE

Method 2: Declaring Along with Structure Definition

C Source
struct Student
{
    int roll;
    char name[50];
    float marks;
} s1, s2; // Variables s1 and s2 declared directly

Terminology Clarification

  • Structure Tag: The identifier following struct (e.g., Student).
  • Structure Members: The variables inside the structure (e.g., roll, name, marks).
  • Structure Variable: The instance variable that actually occupies memory (e.g., s1, s2).

ACCESSING STRUCTURE MEMBERS

Individual members of a structure variable are accessed using the Dot Operator (.), also known as the direct member access operator. If working with a pointer to a structure, the Arrow Operator (->) is used.

Syntax

structure_variable.member_name

Complete C Program: Input and Display Student Information

student_info.c
#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s1;

    printf("Enter Roll Number: ");
    scanf("%d", &s1.roll);

    printf("Enter Name: ");
    scanf("%s", s1.name); // Array name acts as pointer address

    printf("Enter Marks: ");
    scanf("%f", &s1.marks);

    printf("\n--- STUDENT DETAILS ---\n");
    printf("Roll Number : %d\n", s1.roll);
    printf("Name        : %s\n", s1.name);
    printf("Marks       : %.2f\n", s1.marks);

    return 0;
}

Expected Output

Enter Roll Number: 101 Enter Name: Durga Enter Marks: 88.5 --- STUDENT DETAILS --- Roll Number : 101 Name : Durga Marks : 88.50

Line-by-Line Explanation

  • struct Student s1;: Allocates memory for s1 containing roll, name, and marks.
  • scanf("%d", &s1.roll);: Reads an integer directly into the memory location of s1.roll using the address-of operator & applied to the accessed member.
  • scanf("%s", s1.name);: Reads a single word into character array s1.name. Note: & is omitted because character array names decay to base pointers.
  • printf("Roll Number : %d\n", s1.roll);: Fetches the integer stored inside s1.roll and displays it.

STRUCTURE INITIALIZATION

Structure variables can be initialized at the time of declaration, similar to primitive variables or arrays.

1. Compile-Time Initialization (Standard Order)

Values are provided in curly braces {} in the exact order in which members are defined inside the structure.

C Source
struct Student s1 = {101, "Durga", 92.5};

2. Partial Initialization

If fewer initializers are provided than there are members, the uninitialized members are automatically set to zero (for numeric types) or '\0' (for characters/strings).

C Source
struct Student s2 = {102, "Prasad"}; // marks is automatically initialized to 0.0

3. Designated Initialization (C99 Standard)

C99 introduced designated initializers, allowing members to be initialized in any arbitrary order by specifying their member names preceded by a dot.

C Source
struct Student s3 = {.marks = 95.0, .roll = 103, .name = "Mishra"};

NESTED STRUCTURES

1. Simple Definition

A Nested Structure (or structure within a structure) is a structure that includes an instance of another structure as one of its members.

2. Detailed Explanation & Why Used

Real-world entities are often hierarchical. For example, a student entity has personal attributes (roll, name) and a Date of Birth (day, month, year). Rather than cluttering the Student structure with day, month, and year fields directly, we encapsulate date attributes inside a separate Date structure and nest it inside Student. This promotes code reuse and logical modularity.

3. Diagrammatic Representation

Nested Structure Conceptual Layout

struct Student s1
roll
name[50]
struct Date dob
day | month | year

4. Complete C Program: Nested Structure

nested_structure.c
#include <stdio.h>

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int roll;
    char name[50];
    struct Date dob; // Nested Structure Variable
};

int main()
{
    struct Student s1 = {101, "Durga Prasad", {15, 8, 2003}};

    printf("--- STUDENT RECORD ---\n");
    printf("Roll Number : %d\n", s1.roll);
    printf("Name        : %s\n", s1.name);
    printf("DOB (D-M-Y) : %02d-%02d-%d\n", s1.dob.day, s1.dob.month, s1.dob.year);

    return 0;
}

Expected Output

--- STUDENT RECORD --- Roll Number : 101 Name : Durga Prasad DOB (D-M-Y) : 15-08-2003

Member Access Syntax Note

Nested structure members are accessed by chaining dot operators: s1.dob.day accesses the day field within the nested dob structure of s1.

SELF-REFERENTIAL STRUCTURES

1. Simple Definition

A Self-Referential Structure is a structure that contains one or more pointers pointing to an instance of the same structure type.

2. Why a Structure Cannot Contain a Direct Object of Its Own Type

Theoretical Exam Question: Why can't a struct contain an instance of itself?

Answer: If a structure contained a direct object of its own type, calculating the size of the structure would result in an infinite recursive definition (Size = size of int + size of float + size of structure which contains another structure...). The C compiler cannot determine the memory footprint at compile time, causing a fatal compilation error. However, a pointer to the structure has a fixed, known size (typically 4 or 8 bytes depending on system architecture), regardless of what it points to. Thus, self-referential structures store pointers to themselves, not actual instances.

3. Conceptual Visual Diagram

Node 1
data = 10
next = 0x2000
➔
Node 2
data = 20
next = NULL (0x0)

4. Syntax & Basic Code Example

C Source
#include <stdio.h>

struct Node
{
    int data;
    struct Node *next; // Pointer to another structure of type 'struct Node'
};

int main()
{
    struct Node n1, n2;

    n1.data = 10;
    n2.data = 20;

    n1.next = &n2;  // n1 points to n2
    n2.next = NULL; // End of list

    printf("Node 1 Data: %d\n", n1.data);
    printf("Node 2 Data via Node 1 Pointer: %d\n", n1.next->data);

    return 0;
}

5. Use Cases in Computer Science

Self-referential structures are the fundamental building blocks for dynamic data structures in C, including Linked Lists, Stacks, Queues, Trees, and Graphs.

BIT-FIELDS

1. Simple Definition

A Bit-Field is a structure member whose bit width is explicitly declared, allowing memory allocation down to individual bits rather than full bytes.

2. Why Bit-Fields are Used

In embedded systems, hardware device drivers, and network protocol headers, memory is severely constrained or status flags need to be represented as single binary bits (0 or 1). Standard C data types occupy at least 1 byte (8 bits). Storing 8 binary flags using 8 integer variables wastes 31 bytes per flag on 32-bit systems. Bit-fields allow packing multiple variables into a single integer word.

3. Syntax

Syntax
struct structure_name
{
    unsigned int member_name : bit_width;
};

4. Example Code

bit_field_demo.c
#include <stdio.h>

// Without bit-fields: Size = 4 + 4 + 4 = 12 bytes
struct NormalStatus
{
    unsigned int ready;
    unsigned int error;
    unsigned int code;
};

// With bit-fields: Size = 4 bytes total
struct BitFieldStatus
{
    unsigned int ready : 1; // 1 bit (values 0 to 1)
    unsigned int error : 1; // 1 bit (values 0 to 1)
    unsigned int code  : 4; // 4 bits (values 0 to 15)
};

int main()
{
    printf("Size of NormalStatus   : %lu bytes\n", sizeof(struct NormalStatus));
    printf("Size of BitFieldStatus : %lu bytes\n", sizeof(struct BitFieldStatus));

    struct BitFieldStatus s = {1, 0, 12};
    printf("Status - Ready: %d, Error: %d, Code: %d\n", s.ready, s.error, s.code);

    return 0;
}

Expected Output

Size of NormalStatus : 12 bytes Size of BitFieldStatus : 4 bytes Status - Ready: 1, Error: 0, Code: 12

5. Limitations of Bit-Fields

  • Address Operator Restriction: You CANNOT apply the address-of operator (&) to a bit-field member because memory addresses refer to byte boundaries, not bit boundaries.
  • Implementation Dependent: Bit ordering (endianness: left-to-right or right-to-left) is compiler- and hardware-dependent.
  • Arrays of bit-fields are not allowed.

ARRAYS OF STRUCTURES

1. Simple Definition & Explanation

An Array of Structures is a contiguous collection of structure variables stored under a single array identifier. It combines array indexing with structure member access, allowing efficient management of multiple records of the same entity type (e.g., storing records for an entire class of 60 students).

2. Syntax & Accessing

Declaration: struct Student class[60];
Accessing 3rd student's roll number: class[2].roll

3. Complete C Program: Comprehensive Array of Structures Operations

array_of_structs.c
#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student students[3];
    int i, topIndex = 0, searchRoll, found = 0;

    // 1. Input records
    printf("--- ENTER DETAILS FOR 3 STUDENTS ---\n");
    for (i = 0; i < 3; i++)
    {
        printf("\nStudent %d:\n", i + 1);
        printf("Roll No: ");
        scanf("%d", &students[i].roll);
        printf("Name: ");
        scanf("%s", students[i].name);
        printf("Marks: ");
        scanf("%f", &students[i].marks);
    }

    // 2. Display all records
    printf("\n--- ALL STUDENT RECORDS ---\n");
    for (i = 0; i < 3; i++)
    {
        printf("Roll: %d | Name: %-15s | Marks: %.2f\n", 
                students[i].roll, students[i].name, students[i].marks);
    }

    // 3. Find student with highest marks
    for (i = 1; i < 3; i++)
    {
        if (students[i].marks > students[topIndex].marks)
        {
            topIndex = i;
        }
    }
    printf("\nTopper: %s with %.2f marks!\n", students[topIndex].name, students[topIndex].marks);

    // 4. Search student by roll number
    printf("\nEnter Roll Number to Search: ");
    scanf("%d", &searchRoll);
    for (i = 0; i < 3; i++)
    {
        if (students[i].roll == searchRoll)
        {
            printf("Found! Name: %s, Marks: %.2f\n", students[i].name, students[i].marks);
            found = 1;
            break;
        }
    }
    if (!found)
    {
        printf("Student with Roll Number %d not found.\n", searchRoll);
    }

    return 0;
}

STRUCTURES AND FUNCTIONS

Structures can interact with functions in four distinct ways:

  1. Passing individual structure members to a function.
  2. Passing a whole structure variable by value.
  3. Passing a structure variable by reference (using pointers).
  4. Returning a structure from a function.

Pass by Value vs Pass by Reference (Pointer)

Parameter Type Syntax Memory Efficiency Modification Effect
Pass by Value void display(struct Student s) Poor (Copies entire structure byte-by-byte) Changes inside function do NOT affect caller
Pass by Pointer void modify(struct Student *s) Excellent (Passes only 4/8 byte address) Changes inside function directly modify caller

Complete C Program: Structures and Functions

struct_func_demo.c
#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

// 1. Function receiving structure by value
void printValue(struct Student s)
{
    printf("Inside printValue (Copy): Roll = %d, Marks = %.2f\n", s.roll, s.marks);
    s.marks = 100.0; // Will NOT modify s1 in main
}

// 2. Function receiving structure by pointer (Reference)
void updateMarks(struct Student *ptr, float newMarks)
{
    ptr->marks = newMarks; // Arrow operator used for pointer dereferencing
}

// 3. Function returning a structure
struct Student createStudent(int roll, float marks)
{
    struct Student temp;
    temp.roll = roll;
    temp.marks = marks;
    return temp;
}

int main()
{
    struct Student s1 = createStudent(101, 75.5);

    printValue(s1);
    printf("Main after printValue: Marks = %.2f\n", s1.marks); // Unchanged 75.5

    updateMarks(&s1, 95.0); // Pass address
    printf("Main after updateMarks: Marks = %.2f\n", s1.marks); // Updated to 95.0

    return 0;
}

UNIONS IN C

1. Simple Definition

A Union is a user-defined composite data type similar to a structure, but with one fundamental difference: all members of a union share the exact same memory location. The size of a union is equal to the size of its largest member.

2. Detailed Explanation & Shared Memory Concept

While a structure allocates separate memory for each member, a union allocates a single shared block of memory large enough to hold its largest member. Consequently, only one member of a union can store a valid value at any given time. Assigning a value to one member overwrites the previously stored value in that shared memory block.

3. Visual Memory Representation: Structure vs Union

Memory Comparison (Assuming int=4 bytes, float=4 bytes, char[10]=10 bytes)

struct Data (Total: 18 Bytes)

[ int i (4b) ] [ float f (4b) ] [ char str[10] (10b) ]
union Data (Total: 10 Bytes)

[ Shared Memory Block (10 Bytes Max) ]
i, f, and str ALL point to Byte 0!

4. Complete C Program: Demonstrating Union Shared Storage

union_demo.c
#include <stdio.h>

union Data
{
    int i;
    float f;
    char str[20];
};

int main()
{
    union Data record;

    printf("Size of union Data: %lu bytes\n\n", sizeof(record));

    record.i = 10;
    printf("record.i = %d\n", record.i);

    record.f = 220.5; // Overwrites record.i
    printf("record.f = %.2f\n", record.f);
    printf("record.i after record.f assignment = %d (CORRUPTED!)\n\n", record.i);

    return 0;
}

STRUCTURE VS UNION

Feature Structure (struct) Union (union)
Memory Allocation Allocates separate memory for each member. Allocates single shared memory block for all members.
Total Memory Size Sum of sizes of all members (+ padding). Equal to size of largest member.
Member Access All members can be accessed simultaneously. Only one member can be meaningfully accessed at a time.
Value Alteration Changing one member does not affect others. Changing one member overwrites current stored data.
Initialization All or any members can be initialized. Only the first member (or designated) can be initialized.
Use Case When all attributes need to be stored together. When mutually exclusive data needs memory optimization.

STRUCTURE WITHIN UNION

1. Simple Definition & Explanation

A Structure within a Union is a design pattern where a structure is embedded as a member inside a union. This combination is widely used in variant records or hardware protocols where different data formats are stored mutually exclusively, but one or more formats consist of multiple grouped fields.

2. Complete C Program: Structure within Union

struct_in_union.c
#include <stdio.h>

struct Address
{
    char city[30];
    int pin;
};

union Identity
{
    int passportNum;
    struct Address localAddr; // Structure as member of Union
};

int main()
{
    union Identity id;

    // Use Case 1: Using Passport Number
    id.passportNum = 987654;
    printf("Passport Number: %d\n", id.passportNum);

    // Use Case 2: Using Address (Overwrites Passport Number)
    sprintf(id.localAddr.city, "Rayagada");
    id.localAddr.pin = 765001;

    printf("\n--- Local Address ---\n");
    printf("City: %s\n", id.localAddr.city);
    printf("PIN : %d\n", id.localAddr.pin);

    return 0;
}

FILE HANDLING IN C

1. Simple Definition

File Handling in C refers to storing program data permanently on secondary storage devices (hard drives, SSDs) as files, enabling programs to read, write, update, and manage persistent data beyond program execution lifetime.

2. Why Files are Required (Temporary vs Permanent Data)

Variables and arrays stored in primary memory (RAM) are volatile—they are lost instantly when the program terminates or the computer loses power. Real-world software requires persistent storage where records remain intact across computer restarts. File handling bridges RAM and secondary storage.

FILE AND STREAM

1. What is a Stream?

In C, a Stream is a logical interface/channel that bridges a C program and an physical input/output device or disk file. It abstracts device details into a uniform sequence of bytes.

  • Input Stream: Flows bytes from input sources (Keyboard, Disk File) into C RAM.
  • Output Stream: Flows bytes from C RAM to output destinations (Screen, Disk File, Printer).

2. The FILE Structure & File Pointer

In standard C (stdio.h), FILE is a predefined structure type that holds control metadata about a file stream, including the file's memory buffer address, current position indicator, error flags, and end-of-file status.

A File Pointer is a pointer variable declared as FILE *fp; that points to this FILE structure instance managing the stream.

DEFINING AND OPENING A FILE

Files are opened using the standard C function fopen().

Syntax

FILE *fopen(const char *filename, const char *mode);

Example Code with MANDATORY NULL Check

fopen_demo.c
#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "r");

    if (fp == NULL)
    {
        printf("Error: Unable to open file! File may not exist or access is denied.\n");
        return 1; // Exit program
    }

    printf("File opened successfully!\n");
    fclose(fp);

    return 0;
}

EXAM TIP: Why NULL Checking is Mandatory

If fopen() fails (e.g., trying to read a non-existent file or lacking permissions), it returns NULL. Performing read/write operations on a NULL file pointer causes Segmentation Fault crashes. Always write if (fp == NULL) in university exam programs!

CLOSING A FILE

Files are closed using fclose(fp);.

Why Closing Files is Mandatory:

  • Flushes Buffer: Output data is initially written to a RAM buffer. fclose() forces/flushes all buffered data to disk.
  • Releases Resources: Releases operating system file handles and memory resources.
  • Prevents File Corruption: Unclosed files risk losing trailing written data if the program crashes.

String I/O fgets(str, size, fp) Reads a string up to newline/size fgets(buffer, 100, fp);
fputs(str, fp) Writes a string to stream fputs("Hello", fp);
Formatted I/O fprintf(fp, format, ...) Writes formatted text to file fprintf(fp, "%d %s", roll, name);
fscanf(fp, format, ...) Reads formatted data from file fscanf(fp, "%d %s", &roll, name);
Binary Block I/O fwrite(ptr, size, count, fp) Writes raw memory blocks to file fwrite(&s1, sizeof(s1), 1, fp);
fread(ptr, size, count, fp) Reads raw memory blocks from file fread(&s1, sizeof(s1), 1, fp);

FILE ERROR HANDLING

Standard C provides several mechanisms to handle file input/output errors:

  • feof(fp): Returns non-zero (true) if the End-Of-File condition has been reached on the stream.
  • ferror(fp): Returns non-zero (true) if an I/O error occurred during file operations.
  • perror("Error Msg"): Prints a descriptive system error message corresponding to global variable errno.
  • EOF: Predefined macro constant (typically -1) returned by character read operations upon reaching end-of-file.

SEQUENTIAL ACCESS FILES

In Sequential Access, file data is processed strictly in chronological order from the beginning of the file to the end. To read record #50, the program must sequentially traverse past records #1 through #49. Text file processing operates sequentially by default.

RANDOM ACCESS FILES

1. Simple Definition & Explanation

Random Access (or Direct Access) allows a program to instantly read or write data at any arbitrary byte location inside a file without scanning sequentially from the beginning.

2. Functions for Random Access

a) fseek()

Moves the internal file position indicator to a target byte offset.
Syntax: int fseek(FILE *fp, long offset, int origin);

  • SEEK_SET (0): Offset measured relative to Beginning of File.
  • SEEK_CUR (1): Offset measured relative to Current File Position.
  • SEEK_END (2): Offset measured relative to End of File.

b) ftell()

Returns the current byte position of the file pointer relative to the start of the file.
Syntax: long pos = ftell(fp);

c) rewind()

Resets the file position indicator back to the absolute beginning of the file.
Syntax: rewind(fp); (Equivalent to fseek(fp, 0, SEEK_SET);)

Complete Code: Demonstrating fseek(), ftell(), and rewind()

random_access_demo.c
#include <stdio.h>

int main()
{
    FILE *fp = fopen("sample.txt", "w+");
    fputs("ABCDE12345", fp); // Write 10 characters

    printf("Position after writing: %ld\n", ftell(fp)); // Prints 10

    // Move 5 bytes back from SEEK_SET (Beginning)
    fseek(fp, 5, SEEK_SET);
    printf("Position after fseek: %ld\n", ftell(fp)); // Prints 5
    printf("Character at pos 5: %c\n", fgetc(fp));     // Reads '1'

    // Reset to start using rewind
    rewind(fp);
    printf("Position after rewind: %ld\n", ftell(fp)); // Prints 0

    fclose(fp);
    return 0;
}

COMMAND LINE ARGUMENTS IN C

1. Simple Definition

Command Line Arguments are parameters supplied to a C program from the operating system command line (terminal/shell prompt) at the exact moment the program execution is initiated.

2. Detailed Explanation

Normally, C programs prompt the user for input during execution via scanf() or getchar(). Command line arguments allow passing input values upfront before execution starts. This enables scripting, automation, background batch execution, and shell utility development.

3. Syntax of main() with Arguments

C Source
int main(int argc, char *argv[])
{
    // Program logic
    return 0;
}

ARGC AND ARGV

1. Breakdown of Parameters

  • argc (Argument Count): An integer parameter storing the total count of command-line arguments passed to the program, including the program name itself. Thus, argc is always at least 1.
  • argv (Argument Vector): An array of pointers to null-terminated character strings (char *argv[]). Each element holds one argument.
    • argv[0]: Holds the executable name/path of the program.
    • argv[1]: Holds the first user-supplied argument (as a string).
    • argv[2]: Holds the second user-supplied argument (as a string).
    • argv[argc]: Always guaranteed to be a NULL pointer.

3. Note on String Conversion

All command-line arguments are received strictly as text strings (char*). To use numerical arguments in mathematical calculations, convert them using standard library functions like atoi() (ASCII to Integer in <stdlib.h>) or atof() (ASCII to Float).

IMPORTANT DEFINITIONS TO MEMORIZE

  • Structure: A user-defined data type that groups heterogeneous data variables under a single name in contiguous memory.
  • Union: A composite user-defined data type whose members share the exact same memory location.
  • Self-Referential Structure: A structure containing a pointer member pointing to an instance of the same structure type.
  • Bit-Field: A member of a structure whose bit-width is explicitly bounded to conserve memory storage.
  • Stream: An abstract logical interface bridging C software with physical hardware devices or files.
  • File Pointer: A pointer variable of type FILE * holding stream state and pointer offset information.
  • Random Access: The ability to immediately seek, read, or write any byte offset inside a file directly without sequential traversal.
  • argc: Integer parameter passed to main() holding total count of command line tokens passed.
  • argv: Array of character pointers passed to main() containing command line tokens as text strings.
